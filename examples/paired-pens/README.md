# 海报同例：配对栏肉鸡饲喂演示

本例是原创合成数据，用于跟做海报第四张中的分析。Python 3.11+ 标准库即可运行。
在源码仓库根目录执行，`../paired-pens-result` 必须尚不存在：

```sh
python3 -B examples/paired-pens/analyze.py --output ../paired-pens-result
```

Windows PowerShell 将 `python3` 换成 `py -3 -X utf8`。也可从任意工作目录运行脚本的完整路径；
默认输入始终是脚本旁的 `observations.csv`。用 `--input CSV` 显式选择符合本例结构的数据。
脚本不会覆盖输入、已有文件或已有输出目录。

## 数据与预期结果

CSV 保存120条个体记录及各自的区组、栏、处理与身份。六个匹配区组各有两栏，
每栏10只；处理标签在每个区组内分配到整栏。个体记录用于求栏均值，
六个“B减对照”区组差为 `20, -10, 30, 0, 10, -20` g。

- 平均差：`+5.0 g`。
- 配对 t 参考95%区间：`[-14.6331430698, 24.6331430698] g`。
- 区组内整栏标签互换共64种，其中44种至少同样极端；双侧精确 `P=44/64=0.6875`。

原始配方：对照栏均值依次为 `1000,1050,1100,1000,950,1000` g，
B栏均值依次为 `1020,1040,1130,1000,960,980` g。
每栏10个数由栏均值加 `-18,-14,-10,-6,-2,2,6,10,14,18` 得到。
演示分配用 `random.Random(20261027).choice(['L','R'])` 按区组依次生成B栏位置，
结果为前五个区组L栏、最后一个区组R栏。这里的分配与观测都为构造材料。

## 分析口径

实验单位是栏，每个处理6栏。先取栏均值，再等权平均六个区组差，
不把120个个体当作独立的处理重复。随机化检验假设区组内两栏的处理标签
独立且等概率分配、无跨栏干扰，并检验尖锐无效应零假设；双侧统计量为
平均配对差的绝对值，计入与观测值相等的排列。脚本用精确分数比较，避免浮点边界改变计数。

t 区间另使用独立、近似正态区组差的工作模型。固定六个区组时，自由度为5，
所用常数 `t_(0.975,5)=2.5705818356363146` 是自由度5的 Student t 分布0.975分位数，
由该分布的累积分布函数求得；回归测试还以自由度5的闭式CDF独立核对这个分位数。
参考见 [NIST：Student t distribution](https://www.itl.nist.gov/div898/handbook/eda/section3/eda3664.htm)。
该区间与精确随机化检验分别计算，不是该检验反演出的区间。
若合法输入的六个配对差完全相同，结果仍给出精确随机化检验，但参考区间为 `null`，
状态说明样本方差为零，不把零宽区间解释为已确定总体差异。

为使常数与设计相符，本脚本仅接受六个区组、每区组一栏对照与一栏B、每栏10条完整记录。
它拒绝重复个体ID、栏跨区组或处理混用、缺失字段和无穷/非数值；
克数采用最多9位整数、6位小数的固定小数写法，不接受指数记法。
改变区组数、观察层级或失访处理时，需要按新的研究设计选分析方法。

## 输出

新输出目录包含四个文件：

- `pen-means.csv`：各栏均值、观察数和处理身份。
- `paired-differences.csv`：`block,control_mean_g,treatment_mean_g,difference_g`，方向为B减对照。
- `summary.json`：输入指纹、设计、区间与精确检验的数值结果。
- `analysis.md`：可阅读的设计、结果与方法说明。

输入始终保持原样。所有输出由本次实际CSV计算；换一份合法输入会改变结果。
本例在源码中维护，日常精简用户包通过公开仓库查阅。
