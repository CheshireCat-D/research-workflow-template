# Security and research data

The CLI manages local metadata and explicit project copies. It does not execute commands stored in research records, upload data or grant research/data-use approval. Host-agent tools and optional scientific programs have their own execution boundaries.

Report a minimal synthetic reproduction without credentials or unpublished data. If the repository host has private vulnerability reporting enabled, use that channel; otherwise request a private contact route without disclosing the exploit or sensitive payload publicly. No private reporting address or response-time guarantee is claimed by this template.

The supported checks cover ordinary local use, explicit version conflicts and internal path/link safeguards. They are not an adversarial whole-filesystem or power-loss guarantee. File hashes identify versions and drift; they do not authenticate authorship.
