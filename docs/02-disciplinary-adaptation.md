# 学科与方法适配

学科范围采用七类入口，作为可扩充的导航，并非穷尽学科分类体系。先确定研究问题、主张类型与证据单元，再选择方法。所有 ID 以 [catalog.json](../design/catalog.json) 为准。

教育、经济管理、心理、哲学与艺术等专业小类的选择示例见 [专业与问题导航](../profiles/selection.md)。这些示例复用现有入口，不表示新增专业或方法已通过专项任务验证。

## 七类学科画像

| 学科 | 常见对象与证据 | 最小下一项依据检查 | 重点避免的推论 | 常见交付 |
|---|---|---|---|---|
| 理学 | 数学对象、自然过程；命题、推导、计算或测量 | 关键引理、反例、已知极限、误差或收敛检查 | 有限算例当证明，模型自洽当现实有效 | 定理、模型、分析、可复核测量或计算 |
| 工学 | 系统、材料、器件、软件；需求—设计—试验链 | 复现基线，检查关键工况或失效 | 演示或仿真当可靠性、安全认证 | 设计依据、实现、工况、验证与确认材料 |
| 医学与健康 | 人群、疾病、健康服务；方案、记录、估计量 | 识别研究设计、分析单位、偏倚与可回答的问题 | 关联当因果，预测性能当临床效益 | 与研究设计对应的报告、声明和受控数据说明 |
| 农学与生命 | 地块、生物体、生态系统；处理、样本、批次、环境 | 核对独立实验单位、重复层级、空间与季节效应 | 技术重复当生物重复，单点单季当普遍有效 | 实验设计、材料方法、环境元数据与适用范围 |
| 人文 | 文本、史料、作品、概念；版本、语境、论证与竞争解释 | 核对关键版本与引文，比较有力的替代解释 | 缺少记录当事件不存在，引文存在当解释成立 | 可定位材料、解释路径、版本和译释说明 |
| 社会科学 | 个体、制度与社会过程；调查、访谈、田野或历史资料 | 按量化、定性或混合方法检查识别、测量与分析依据 | 控制变量当因果识别，编码一致当解释正确 | 与方法相符的分析、研究者位置及外推边界 |
| 法学 | 规范、裁判、制度与实施材料；法域、版本、理由及引证 | 明确相关时点、施行与过渡范围、效力或判例地位的依据 | 公布当施行，摘要当判决理由，外国裁判自动当本地拘束规则 | 有范围的法律分析、法源对照、竞争解释及待核事项 |

画像提供常见风险提示，不把“医学”自动等同临床试验，也不把“人文”自动等同无需伦理与许可处理。涉及人、动物、危险实验、生态干预、受限数据或社群材料时，按具体行动和当地适用机制判断治理义务。

## 十类方法适配器

| ID | 核心检查 | 常见变体或组合 |
|---|---|---|
| `formal-theory` | 定义、假设、量词、证明义务、反例；形式核验注明范围 | 数学证明、理论 CS、解析推导；不强制形式化工具 |
| `computational` | 实现与模型区分、输入版本、误差、收敛、资源与复现 | 数值仿真、经验算法、语料计算；预测评估再组合量化方法 |
| `measurement-experiment` | 校准、测量模型、分配、实验单位、误差和不确定性 | 实验室、田间、动物实验；按适用条件选择随机化或盲法 |
| `engineering-design` | 需求、约束、工况、基线、权衡、失效、验证与使用场景确认 | 器件、系统、材料、软件原型 |
| `empirical-quantitative` | 区分描述、关联、预测、因果；单位、抽样、缺失、识别、切分与不确定性 | 观察研究、调查、随机干预、诊断预测；不默认都需要显著性检验 |
| `qualitative` | 材料选择、情境、研究者位置、分析路径、负面案例与竞争解读 | 访谈、民族志、案例、参与式研究；不统一规定编码一致率或饱和标准 |
| `historical-interpretive` | 版本、来源批判、语境、翻译、材料缺口、解释路径与反对意见 | 档案、文本、艺术作品、历史比较 |
| `conceptual-normative` | 概念区分、前提、推理、价值立场、反对意见、适用范围 | 哲学、伦理、规范理论；经验事实不能单独推出“应当” |
| `legal-analysis` | 法域、事实与研究时点、施行及过渡、权限与效力、裁判地位、后续处理、精确引证 | 法律解释、裁判分析、比较法；规范建议与实施效果另组合相应方法 |
| `evidence-synthesis` | 综合目标、来源范围、选取理由、评价与综合方式 | 系统、范围、叙述或解释性综合；只有声明系统方法时才启用相应系统检索要求 |

“最小验证”在通用版指最小下一项依据检查。它可以是证明一步、核对史料、试编码、误差检查或失效测试；不得把可量化、可证伪的预测设为所有研究的唯一入口。

## 组合规则

1. 按每个重要主张选择所需方法，而非仅给整个项目贴一个标签。例：算法复杂度结论用形式方法，现实预测效果用量化评估。
2. 学科画像只给建议。方法没有选定时，先澄清决定下一步所必需的信息，不自动启用全部检查。
3. 适用义务按其范围累加。相互矛盾的抽样、匿名化或开放共享要求要登记，说明受影响材料和行动，由有职责的人处理；不能取最宽松分支，也不能把所有学科最严条款无条件叠加。
4. 期刊风格只影响呈现，不能覆盖证据边界、知情同意、数据权利或其他适用义务。治理来源冲突时记录来源、权威范围和日期，系统不自行裁定法律效力。
5. 统一证据关系保留分歧，不用支持材料数量、代理多数票或跨学科总分自动裁决。研究者明确说明整合依据。

实际方法绑定应记录方法 ID、画像版本、所属变体、适用的主张／活动／材料及选择理由；项目级列表只用于发现可能需要的能力，不把全部义务复制到每个主张。画像更新后，由研究者或代理定位并复核受影响的绑定，不静默改变既有判断。

CLI 保存的 `profile_version` 字符串不会自动使活动变为 `stale`；需要检测画像字节变化时，将实际使用的本地画像登记为 evidence，并作为已完成活动的输入。只读检查才会按现有文件指纹与依赖报告漂移，随后显式复核和更新登记，而不自动替换原结论。

画像的 `supported_variants` 声明指导范围，`options` 的 `implementation.variant_evidence` 另列显式变体绑定、仅方法级记录与不可取得的记录；实际工作与内容判断仍查对应审阅，摘要不重新认证结论。旧任务可能只记录方法、未填变体；摘要保留这种未归属状态，不凭任务名补写，也不据此断言该工作没有执行。项目内副本不包含完整任务材料，摘要说明其不可用范围。

## 组合示例

- **医学预测模型**：`medicine-health` + `computational` + `empirical-quantitative`。按患者、机构或时间检查划分和调参，登记校准、外部适用性及数据权利。准确率提升不自动建立临床效益。
- **无人机作物识别**：`agriculture-life` + `engineering`，组合计算、量化和必要的田间实验。检查地块、地点、季节层级，同一地块多张图片不能直接增加独立样本量。
- **数字人文**：`humanities` + `computational` + `historical-interpretive`。保留 OCR、版本与语料覆盖限制，将计算模式与原文细读相对照；词频变化不能独自确立历史因果。
- **法理与比较法**：`law` + `legal-analysis`，需要制度价值论证时再加 `conceptual-normative`。各法域先独立核对规范与裁判的时空和权威范围，再论证比较关系；立法建议与现行法解释分开。实证法学按研究设计另选量化或定性方法。

法学的五项检查及逐条台账见 [法律解释与法源分析](../profiles/methods/legal-analysis.md) 和 [法学项目模板](../profiles/templates/legal-research.md)。当前专门测试使用两组虚构法域材料，记录实际分析、独立代理审阅与恢复行为，见 [法学任务](../evals/legal/README.md)；不表示所有法系、部门法或真实案件均已验证。

医学与健康的报告规范入口参考 [EQUATOR Library](https://www.equator-network.org/library/)；史料、引证和解释责任参考 [AHA 标准](https://www.historians.org/resource/statement-on-standards-of-professional-conduct/)。这些来源用于相应范围的适配，不授权把一种学科规范推广为所有研究的统一门槛。具体来源与核验范围见 [规范来源地图](06-source-map.md)。

## 专项任务示例

七类学科各补充一项[已实际执行的专项任务](../evals/disciplinary/README.md)，包含原始合成材料、分析/代码、修订短稿与独立代理复核。解析推导、艺术阐释等示例按其实际输入和工作报告范围；它们补充既有证据，不自动扩大方法画像的全部变体声明。可用这些案例了解输入如何转化为可核对产物，再为自己的问题选择方法。
