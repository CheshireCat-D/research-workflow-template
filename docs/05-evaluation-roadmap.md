# 当前检查与回归材料

本包只维护一套当前源文件和一份当前发行归档。软件执行结果的唯一入口是[当前核验记录](../evals/current/latest.json)；具体 ZIP 的身份、干净解压和分发核验随 `dist/release-validation.json` 提供。过去的发行阶段通过记录已移出包内，不再用多个 `latest.json` 表示不同软件状态。

## 依据与任务组分别读取

| 依据 | 位置与用途 | 可报告的范围 |
|---|---|---|
| 当前软件检查 | `tests/`、当前核验记录与发行包伴随记录 | 结构、引用、接口、文件指纹、安全边界及实际运行环境 |
| 基础技能维护请求 | [实际请求记录](../evals/current/skill-task-checks.json)的 `cases` | 代码修复、缺失数据决策、局部润色、SVG改图及资料索引的五项有限任务 |
| 跨材料核对 | 同一记录的 `cross_material_review` | 共享结果修订、理论命题范围与局部编辑边界三项任务 |
| 正文表达 | 同一记录的 `direct_prose` | 实验结果直述、观察性关联修订与按请求解释推断区别三项任务 |
| 返修规划与执行 | 同一记录的 `revision_workflow` | 限时计划与实际修订两项任务，分别核对依赖、工时、回复与修改位置 |
| 双向引证核对 | 同一记录的 `citation_audit` | 合成来源包中的复合主张、错引缺引、同研究版本与合理综合；原稿保持不动 |
| 基础研究素材 | [基础回归任务](../evals/d2/README.md) | 数学证明、计算实验和史料解释的原始请求、输入、产物与独立内容审阅 |
| 跨学科研究素材 | [跨学科回归任务](../evals/d3/README.md)、[场景映射](../evals/d3/coverage.json) | 创新、候选对抗及理工医农和人文社科的代表性任务 |
| 法学研究素材 | [法学回归任务](../evals/legal/README.md)、[新增场景映射](../evals/legal/coverage.json) | 虚构法域中的规范时效、权限、裁判地位、比较法与引证分析 |

21项冻结代表性研究任务由基础组3项、跨学科组16项和法学组2项组成，与上面的各组技能任务分别读取；技能任务观察不扩展为新增学科内容认证。`d2`、`d3` 是既有测试素材组的技术标识，不是保留的旧软件版本。各组材料、实际产物、规范化登记和冻结审阅指纹继续用于当前回归；删除它们会破坏复现与测试。旧组的原始材料与审阅记录不因新增方法或软件整理而改写。

## 运行当前检查

```sh
python3 -B tools/check_core.py --test-timeout 360
python3 -B tools/release_package.py check
```

检查在临时目录重建项目，覆盖登记、配置、依赖与记录版本、标准输入、批量失败回滚、只读恢复、技能接入与显式升级。回归会重跑材料中的适用代码、核对明确结果字段和指纹；不会调用模型重新产生一次独立内容评审。

[架构场景](../design/scenarios.json)由[原场景覆盖](../evals/d3/coverage.json)和[法学新增场景覆盖](../evals/legal/coverage.json)共同连接到实际任务，不以场景ID存在代替执行，也不让旧任务继承新增方法的验证结论。方法画像与实际任务的对应在[稳定目录](../design/catalog.json)中维护。

## 当前结果的边界

每次核验记录实际解释器、操作系统、命令退出状态及未覆盖内容。某个平台未出现本轮成功记录时，不从旧结果推定当前通过；托管CI也以真正的远程运行日志为准。当前发行包内容变动后，需要重新审阅来源、刷新清单并重建验收。

软件检查、实际有限任务和内容判断相互独立。登记通过、数值一致、字段或哈希一致不认证证明、因果解释、全局新颖性、伦理批准或期刊录用。代表性任务也不等于穷尽所有学科变体或人类专家认证。
