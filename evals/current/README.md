# 当前核验入口

本目录仅保存当前一轮软件核验结果，不累积旧发行阶段记录。[latest.json](latest.json)由实际执行后填写；整理过程中或尚未执行时明确标记待核验，不把移出的旧结果改名视为新成功。

当前的不同任务回归素材继续放在[基础素材](../d2/README.md)和[跨学科素材](../d3/README.md)。它们的原始输入、科学产物和独立审阅指纹用于当前测试，不包含另一套旧软件。

最终ZIP的SHA、确定性构建和干净解压结果随 `dist/release-validation.json` 提供，不嵌入自身归档形成递归指纹。源码、已测软件/指导与测试指纹、最后新增的交付元数据各自记录适用范围。
