# 待审查材料，不是冻结包

T/D各含 `initial`（A可见资料，project_payload供复制到独立项目）、`events`（仅组织者B前注入）、`stage-C`（仅C投放）、`reference`（组织者/评审键）。shared/含共同协议、记录、A-D阶段请求、100分rubric及独立工程探针。不要把整个design根给执行者；当前没有freeze.json，不得宣称已预注册或已执行对照。

A/B/C/D同一研究链具有依赖。来源/初始参数与修订事件是回顾性构造，不能叫原论文/数据作者的真实更新。T只改rho 1→4；D只改评价起日Oct1→Nov1。真正来源和脚本/冻结模型不变。三臂共同依赖图为参数+选择+原始来源/代码(及D模型)→CALC→SYNTH；SOURCE-CHECK是有效独立支路。source-only与scratch明确排除内容跟踪。

原始PDF和CSV目前只在此私有临时材料中，不得复制进公开评估源。builder会生成初始/修订标准数值，但这不是独立盲态答案核验；冻结前应另由材料/实现无关审计者核对来源身份、两次计算、关系集合和评分公平性。

尚需组织者决定：每臂预算与真实环境，阶段路径投放与隔离，具体臂指导/核心包SHA，控制顺序，身份冻结和只读快照工具、版本/批次探针接口适配。不可因某组失败改题或补台账。
