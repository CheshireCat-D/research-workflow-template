# 组织者与独立机械核验建议

冻结前由不参与执行/盲评的审计者核对：T公式及rho固定条件与给定原始版本定位；T两组数值；D原始切片8645行的SHA及固定72个均值与原2011训练期、两评价期的指标（独立实现或原始数据直接求和，绝不从提供结果反抄）；共同义务图的可实现性、独立来源分支、100分合计。builder自行运行提供代码的核对只算接口测试，不算独立答案验证。

建议运行时快照捕获项目每项相对路径、种类、文件完整SHA、文件mtime_ns、目录mtime_ns；符号链接另存目标且禁止自行跳出项目。不要比较atime。B/D答卷和stdout/stderr应在项目外。每阶段源/模型/脚本及共享约束按初始哈希核对；B前后除notes/parameters.json外全部不应由注入器改动。注入过程前后整体快照与其receipt分开保留，不能单凭注入器自报只有一文件变化。

实际执行记录应由组织者捕获或回读工具记录核验，子agent自报只是一层证据。C必须保留“先保存漂移快照→原始只读输出→真实复算/依赖复核→最终当前断点”的先后证据；最终干净输出不能代替中间输出。工程探针在独立封存副本执行，不能把故意冲突的试写混入主链。

数据与理论数值参考容差建议绝对1e-10；科学输入/代码/模型/官方资料及单文件参数事件用精确SHA。表中展示舍入值可接受，但canonical result不可因展示舍入改变参数。语义ID允许不同存储格式；若某组没有记录某关系或本地绑定，不能替它从题面补完其实际项目状态。

B参考集合CALC、SYNTH、SOURCE-CHECK基于明确共同义务图。若执行者在A额外创建其他真实依赖活动，按其实际关系补充评估；不能只按三个预期ID机械误判多出的正确失效为误报。反之A遗漏必要依赖导致B无告警，仍保留A错误与B后果。保留source-only未检查内容、非必需文件和未登记scratch覆盖的诚实范围；不要求自动发现未声明依赖。

C新checkpoint/快照当前≠旧活动重新有效是通用语义义务，并非RWT专有术语给分。A/B若选择自己hash后丢弃旧hash，应据实际历史/结论判断是否失去旧工作依据。没有自动脚本不直接当内容失败；其人工恢复若正确也应得相应分。机械机制与定制负担另表。

D迁移使用每组真实项目全部文件；移除/隐藏旧位置及原工具包/公共缓存，统一提供新路径和共同解释器。不得暗补标准说明或runtime。路径迁移不是输入变更；若复制保留mtime策略不一致，应仅使用已有身份SHA和相对逻辑位置判研究版本，不人为制造mtime误报。最终只读要求从迁移后首次运行之前开始比较。

评分者不见arm映射、执行日志和其他组先前分数；机械审计者可核验日志。统一语义答卷可能仍暴露方法，不能宣称完美盲法。所有科学分与关键错误原貌保留，独立复核主要差异，失败仍在原分母，不因不利结果换题或补跑最佳版本。结果只用于这两条有控制事件的项目链，不能外推真实长期平均节省工时、全部学科可靠性或GitHub排名。
