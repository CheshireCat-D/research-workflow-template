# 四任务三组受控先导协议 v1

本协议在首次执行前冻结。问题是：同一宿主模型核对四份完整给定材料时，额外加载 RWT 指导或固定外部指导，会出现什么可观察差异？这是四个目的性选取的小任务，不估计总体准确率、领域排名、时效或成本收益。成立和错误材料各有数学、统计一份；题目为本次原创，未复用 R17/R42/R63/R88。公开题目不标真值。

## 冻结与三组

freeze.json 绑定任务、参考评分键、运行配置、协议、共同提示和记录模板的 SHA256。指导采用逻辑名与 SHA256；临时绝对路径不进入公开清单。所有组使用相同任务原文、共同提示、模型配置请求、输出/工具预算和工具；差别仅为加载的指导正文。

- baseline：不额外读取 skill 正文。宿主已有的技能 metadata catalogue 对三组同样可见；这不是完全无技能知识的裸模型。
- rwt：读取冻结的 rw-review、rw-validation、skill-bridge、protocol，数学题再读 formal-theory，统计题再读 empirical-quantitative。只核对材料、交付报告，不初始化项目或写研究登记。
- critical-thinking：读取 K-Dense scientific-critical-thinking/SKILL.md，可按需读冻结的八个参考。固定上游 commit 5f2bc0341354fd5590aef76a533ada1e1e5b4e62。本次暂存文件对尾部空行做过归一化；清单 SHA 标识实际交付字节，不声称与上游原始字节完全一致。第三方正文不收入本仓库。

外部源为 https://github.com/K-Dense-AI/scientific-agent-skills/tree/5f2bc0341354fd5590aef76a533ada1e1e5b4e62/skills/scientific-critical-thinking 。RWT 指导取冻结时版本，后续产品修改不替换本次实验指导。此比较器与形式证明任务的领域适配差异必须保留，不能将结果解释为通用优劣。

## 执行

每个 task × arm 新建一次 fork_turns=none 上下文，共12次。父上下文不得带入任务答案、参考键、其他报告、组间结果或既有 variance/cage 练习。模型和 reasoning effort 均不 override，继承同一父设置；宿主不报告的 effective 值记 null、source=unknown，不可猜测。temperature、seed、硬输出 token 上限同理；请求一致不等于已核验实际一致。

每次最多8次工具调用、报告最多5000 Unicode 字符，均为请求限制，不声称宿主已强制实施。禁联网、外发、调用其他 agent、读取个人技能包、其他任务、参考键、协议评分部分、其他组正文或报告。允许只读对应任务及本组冻结指导，允许用同一标准库做本地数学计算。报告与 execution.json 的写入属于工具预算。不得安装依赖、修改题目或指导。实际读入的逻辑名与 SHA、工具次数、输出、违规、失败及未知项逐次记录。

共同提示见 executor-prompt.md，仅替换 task 路径、允许指导列表、输出目录和匿名 trial 标签。不要为某组补充数学/统计提示；不要因任务真假调整预算、追问或重跑。无论拒答、超限、失败或未完成都保留初次结果；追加试验须新协议版本，不能替换不利初次结果。执行顺序由协调者在首次运行前排定并记录，不按中途成绩调整。

上下文隔离、禁止额外读取和盲法均是工具/提示层面约束与执行者自报；本先导没有 OS 级文件隔离审计。所有组可见同一宿主工具和技能 metadata。手工耗时只作执行观察，不作性能基准。

## 盲裁定

协调者冻结全部报告字节后随机重命名为不含组别的 submission_id，独立保存 arm 映射。裁定者仅收到一题原文、该题匿名报告、reference-key.json 的对应条目及裁定模板；不得见 execution.json、arm 映射、指导名或其他报告。报告若自行泄露组别，记录盲法违规，不伪装为成功盲审。

按五项具体义务各0/1/2分：2为正确且有可核对论证，1为实质部分完成，0为错误、缺失或仅列术语。允许与参考不同的正确证明、反例和计数路线。评分须写报告中的证据位置及理由；不按关键词命中、篇幅、引用数量或模板完整度给分。单给正确真假判断只能得对应判断项。额外捏造的主要错误另列，不把可选润色当主要误报；裁定者检查其对对应义务的影响。评分者不能调用执行 agent 修复答案。

## 记录与汇总

协调者使用 templates/；每个 trial 绑定 freeze、task、report、execution、匿名裁定的实际哈希。actual_reads 用清单逻辑名；哈希在读入时记录，不以报告完成后重读冒充当时所读。读取未知文件时如实写入并列违规。

summary.py 不调用模型，只核对冻结输入和记录完整性，读取人工语义评分。默认要求12个互不重复 task/arm 记录且全部执行、评分、无违规；缺失/未评分/失败时报错。--allow-incomplete 可输出 status=incomplete 和缺项，但不将未评分、失败记录当0分或成功。重复、坏哈希、路径逃逸和不一致评分始终报错。它不自动判断证明或统计推断正确。

仅报告逐题逐组评分、实际发现、误报、漏报、违规、未知设置和失败。即使12次记录齐全，complete 也只指本先导记录闭合，不表示科研成功或总体准确率。effective 设置仍未知时明确标记，不能描述为已核验的同模型同随机种子基准。
