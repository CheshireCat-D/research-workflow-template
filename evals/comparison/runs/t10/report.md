# 核对结论

主张不成立。一致收敛以及每个函数在0处的导数为0，不能保证极限函数在0处可微。给定证明的失效点是把任意小的固定误差 ε 除以趋于0的 |h| 后，仍当作趋于0的误差。

## 满足全部条件的反例

对正整数 n，取

\[
f_n(x)=\sqrt{x^2+n^{-2}},\qquad -1\le x\le1.
\]

每个函数都在闭区间上连续。根号内严格为正，故它在开区间上可微，且

\[
f_n'(x)=\frac{x}{\sqrt{x^2+n^{-2}}},\qquad f_n'(0)=0.
\]

它们一致收敛到 f(x)=|x|。事实上，对全部 x∈[-1,1]，

\[
0\le f_n(x)-|x|
=\frac{n^{-2}}{\sqrt{x^2+n^{-2}}+|x|}
\le\frac1n.
\]

在 x=0 时等号成立，因此一致误差恰为1/n，趋于0。

但 f(0)=0，且对非零 h，

\[
\frac{f(h)-f(0)}h=\frac{|h|}{h}
=\begin{cases}1,&h>0,\\-1,&h<0.\end{cases}
\]

左右差商极限不同，所以 f 在0不可微。这一函数列同时满足连续、可微、原点导数为0以及闭区间上一致收敛的全部条件。

## 证明中的确切问题

稿件给出的三角不等式本身正确。问题出在最后一步：固定 ε>0 并选定 N 后，虽然第一项随 h→0 趋于0，但 2ε/|h| 趋于正无穷，不能由此推出右边趋于0。

“ε 可以任意小”并不能修复这一步。若为了压低第二项而让 ε 随 h 变化，相应的 N 也会随 h 变化；已知 f_N'(0)=0 只控制固定 N 时的差商，未提供对所有这些 N 都有效的统一邻域。

反例还可直接显示这种差别：

\[
\frac{f_n(h)-f_n(0)}h
=\frac{h}{\sqrt{h^2+n^{-2}}+n^{-1}}.
\]

固定 n 时它随 h→0 趋于0；而取 h=1/n 时，它恒等于 1/(√2+1)，并不趋于0。

## 可用的更正与可选建议

实质性更正是撤回原结论，或补充一致控制原点差商的条件。例如，若另有：对每个 η>0，存在 δ>0，使所有 n 及所有 0<|h|<δ 都满足

\[
|f_n(h)-f_n(0)|\le\eta|h|,
\]

则固定这样的 h，令 n→∞ 即得 |f(h)-f(0)|≤η|h|，从导数定义可知 f'(0)=0。此条件是新增假设，原题并未给出。

可选表述建议：将一致收敛的误差记为 ε，将目标差商误差另记为 η，并明确 N 与 δ 各自依赖哪些参数，有助于避免混淆；单独改符号不会使原证明成立。
