## 关键推理核验

固定任意 ε>0。假设1对误差 ε/3 给出 δ₁>0；f 在闭区间上的一致连续性给出 δ₂>0。取 δ=min(δ₁,δ₂)，便可同时控制全部 fₙ 与 f 的邻近点误差。这里 δ 与 n 无关，符合最后要求的一致收敛量词。

有限有理中心覆盖的构造有效：对每个有理数 q∈[0,1]，取相对开集 U_q=(q−δ/2,q+δ/2)∩[0,1]。有理数稠密保证这些集合覆盖 [0,1]；闭区间紧致保证存在有限子覆盖 U_{q₁},…,U_{qₘ}。因此每个 x 都有一个中心满足 |x−qᵢ|<δ。相对开集也正确处理了端点 0 和 1。

对每个有限中心，假设2给出 Nᵢ，使所有 n≥Nᵢ 均有 |fₙ(qᵢ)−f(qᵢ)|<ε/3。取有限最大值 N=maxᵢNᵢ，得到一个同时适用于全部中心的阈值；N 与 x 无关。

于是对所有 n≥N 和所有 x∈[0,1]，选上述中心 qᵢ 后，

|fₙ(x)−f(x)| ≤ |fₙ(x)−fₙ(qᵢ)| + |fₙ(qᵢ)−f(qᵢ)| + |f(qᵢ)−f(x)| < ε/3+ε/3+ε/3=ε。

这正是：对每个 ε>0，存在 N，使所有 n≥N、所有 x∈[0,1] 都满足该误差界。因此 fₙ 在 [0,1] 上一致收敛到 f。
