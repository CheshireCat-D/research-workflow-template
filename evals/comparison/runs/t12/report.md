# 核对结论

稿件的单侧尾部计算正确，但完整检验的错误率及本次显著性结论错误。事先写入一个依赖观测符号的方向选择规则，不能保证检验的拒绝概率不超过0.05。应按完整规则的零假设分布校准。

## 可复算的核验

令 K 为8对中 D_i=+1 的对数。尖锐零假设下 K~Binomial(8,1/2)，且 S=2K−8，每个符号向量概率均为1/256。观测 K=7、S=6，因此

P₀(S′≥6)=[C(8,7)+C(8,8)]/256=9/256=0.03515625。

这一步没有算术错误；问题出在把它直接作为“先选方向再检验”程序的有效p值。

| 绝对统计量 abs(S) | 选定单侧尾部概率 | 原规则是否拒绝 |
|---|---:|---|
| 8 | 1/256≈0.00390625 | 是 |
| 6 | 9/256≈0.03515625 | 是 |
| 4 | 37/256≈0.14453125 | 否 |
| 2 | 93/256≈0.36328125 | 否 |
| 0 | 163/256≈0.63671875 | 否 |

S=0时按方案使用上尾，表中概率已经计入等号。故完整拒绝域为 S∈{−8,−6,6,8}，即 K∈{0,1,7,8}。两侧事件互斥，实际第一类错误概率为

P₀(拒绝)=[C(8,0)+C(8,1)+C(8,7)+C(8,8)]/256
=18/256=0.0703125，亦即7.03125%，超过5%。

直接枚举全部256个符号向量也得到18个拒绝结果。

## 本次相容的尾部概率与更正

完整规则容许正负两侧中任一侧出现同等或更极端结果。本次相容的尾部概率为

p完整=P₀(|S′|≥6)=P₀(S′≥6)+P₀(S′≤−6)
=18/256=0.0703125。

也可按原规则报告的单侧尾部值排序，计算 P₀(p选择(S′)≤9/256)，结果同为18/256。这里包含等值结果，没有使用正态近似或中间p值。

因此，按校准后的完整检验，本次在0.05水平不拒绝尖锐零假设，不能据此宣称“处理提高结果”。观测差的平均值为6/8=0.75，仍可作为本次样本的描述；不拒绝也不等于证明处理无效。

实质更正是报告完整程序的p值并修改显著性结论。对于这一离散分布，采用 p完整≤0.05 时仅 |S|=8 会拒绝，其实际错误率为2/256=0.0078125。等价地，将选定单侧尾部的阈值改为0.025也能控制两侧总错误率；本次9/256不满足该阈值。若未来预先固定只检验提高方向，则9/256是该固定上尾检验的正确概率，但这不能追溯性地替换本题已经规定的双向选择程序。

预先规定规则的价值在于让整个程序可核验；错误率控制仍须通过该程序的拒绝域来证明。
