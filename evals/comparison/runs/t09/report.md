# 论证核对

结论成立，稿件证明正确。在给定条件下，函数列在整个闭区间上一致收敛到 f；没有影响结论的实质性错误。

关键核验如下。

1. 固定任意 ε>0。一致等度连续给出 δ₁>0，适用于所有 n 及所有区间内的点；f 在紧区间上的一致连续性给出 δ₂>0。取 δ=min(δ₁,δ₂)，即可同时保证稿件中的两个 ε/3 估计。这里 δ 与 n、x、y 均无关。
2. 有限个有理中心的覆盖确实存在。对每个有理数 q∈[0,1]，令 U_q=(q−δ/2,q+δ/2)∩[0,1]。由有理数稠密，这些相对开区间覆盖 [0,1]；由紧致性可选有限子覆盖 U_{q₁},…,U_{q_m}。因此每个 x 都有某个中心满足 |x−q_i|<δ/2<δ，包括区间端点。
3. 在每个有限中心上，假设2给出 N_i，使所有 n≥N_i 均有 |f_n(q_i)−f(q_i)|<ε/3。有限最大值 N=max_i N_i 存在，并同时控制全部中心。虽然选中的 i 可随 x 改变，N 不随 x 改变。
4. 对任意 x∈[0,1] 与 n≥N，选择覆盖 x 的中心，得到

   |f_n(x)−f(x)| ≤ |f_n(x)−f_n(q_i)| + |f_n(q_i)−f(q_i)| + |f(q_i)−f(x)| < ε。

这正是“一切 n≥N、一切 x∈[0,1]”的一致收敛要求，而非仅逐点收敛。论证只使用题目允许的事实，不依赖未给出的有界性假设或外部定理。

实质性问题：无，无需更正，也无需反例。
