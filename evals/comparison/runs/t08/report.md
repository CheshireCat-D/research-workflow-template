# Q58 核对报告

主要结论不受支持。稿件的单侧概率算术正确，但该完整检验在尖锐零假设下的实际拒绝概率为 **18/256＝0.0703125（约7.03%）**，超过宣称的5%。事先规定如何根据数据选方向，并不能保证该规则具有所称错误率；需要按完整规则校准。

## 关键核验与实质错误

设正号个数为 K。给定随机化条件下，K 服从 Binomial(8, 1/2)，S＝2K−8，256个符号向量等概率。这些前提和稿件计算

P₀(S′≥6)＝[C(8,7)＋C(8,8)]/256＝9/256＝0.03515625

均正确。这只是固定取上尾时的概率。

完整规则也会在负方向拒绝。各个 S 值的符号向量数与所报概率如下；尾部均包含等号。

| S | 向量数 | 规则所报 p |
|---:|---:|---:|
| −8 | 1 | 1/256 |
| −6 | 8 | 9/256 |
| −4 | 28 | 37/256 |
| −2 | 56 | 93/256 |
| 0 | 70 | 163/256 |
| 2 | 56 | 93/256 |
| 4 | 28 | 37/256 |
| 6 | 8 | 9/256 |
| 8 | 1 | 1/256 |

因此 p≤0.05 当且仅当 S∈{−8,−6,6,8}，即 K≤1 或 K≥7。两侧事件互斥，故

P₀(拒绝)＝[C(8,0)＋C(8,1)＋C(8,7)＋C(8,8)]/256
＝(1＋8＋8＋1)/256＝0.0703125。

错误在于将“事先规定的、依赖观测方向的选尾规则”当作“事先固定一个方向的单侧检验”。预先写明规则让分析可复查，但不改变其拒绝域，也不自动控制拒绝概率。

## 与方向选择相容的更正

用 T＝|S| 衡量所选方向的极端程度，并在每个零假设符号向量上重做同一方向选择。本次 T＝6，应计算

p调整＝P₀(|S′|≥6)
＝P₀(S′≥6)＋P₀(S′≤−6)
＝18/256＝0.0703125。

等价地，这是零假设下“完整规则报告的单侧 p 不大于本次 9/256”的概率；本例因分布对称，它恰好等于两倍所报单侧概率。因此本次不能据此在0.05水平拒绝尖锐零假设，也不能据此作出该水平下的“处理提高结果”宣称。这一结果不证明处理无效。

若采用上述经选择校准的 p≤0.05 规则，本离散样本中只有 |S|＝8 会拒绝，实际错误率为2/256＝0.0078125。若原本独立于数据固定“提高”方向，上尾9/256可用于有效的单侧检验；这不是本题已经实施的规则，不能事后改称如此。

## 实际复核

使用 Python 标准库 itertools 枚举全部256个符号向量，逐个计算 S、依其符号选尾并与0.05比较；得到18个拒绝向量。对本次 |S|＝6 的双侧尾部也得到18个向量，与上述二项式计数一致。此核对在题设给定的随机化分布内是穷尽计算，无需外部数据。没有发现另需更正的随机化或算术问题。
