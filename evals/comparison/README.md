# 四题三组先导

先读 [协议](protocol.md)。任务在 tasks/，参考答案与评分义务只给裁定者：reference-key.json。执行者只收到对应任务、[共同提示](executor-prompt.md)、执行模板和本组冻结指导；不要把本目录整体发给执行者。

freeze.json 固定输入身份；指导正文暂存于协调者的临时目录，不随本仓库分发。三组为 baseline、rwt、critical-thinking。每次新上下文，共12次。配置、指令隔离及盲法的可验证范围见协议。

完成后协调者将报告、执行记录、匿名裁定收入本目录，并在 trials/ 新建一条 trial JSON；字段见 templates/。匿名裁定不含 arm，trial 是裁定后才合并的协调者记录。actual_reads 每项包含 logical_name 和 sha256；指导项使用 freeze 中的 rwt/... 或 competitor/... 名称。

从仓库根目录运行：

    python3 -B evals/comparison/summary.py --allow-incomplete
    python3 -B evals/comparison/summary.py
    python3 -B -m unittest discover -s tests -p test_comparison.py -v

第一条允许输出未完成状态；第二条只有12条完整有效记录才返回0。summary.py 不产生评分、不启动模型，不把四题得分解释为总体准确率。

## 本轮实际结果

12次执行和12次独立单报告 AI 裁定已完成，报告字节先固定、随机命名，再交给不见组别映射的全新裁定上下文。[汇总记录](summary.json)通过严格闭包校验；逐份证据、理由和报告指纹保存在 adjudications/、runs/ 与 trials/。

| 题目 | 不额外读取技能正文 | RWT | 固定外部指导 |
|---|---:|---:|---:|
| Q11 | 10/10 | 10/10 | 10/10 |
| Q24 | 10/10 | 10/10 | 10/10 |
| Q37 | 10/10 | 10/10 | 10/10 |
| Q58 | 10/10 | 10/10 | 10/10 |

本次没有观察到评分差异或捏造的主要异议，不能据此声称 RWT 优于比较器。任务过小并出现满分上限效应；每组每题只有一次执行，且未知 effective 模型、推理强度、随机种子与 token 数，不能当成已核验同模型同随机种子的准确率或成本基准。四题现已公开，后续未见任务评估应另行冻结新材料。

裁定者均为 AI，真人参与者为0。冻结协议末段的“人工语义评分”表述不够精确；本轮实际采用独立 AI 语义裁定，未将其冒充人类专家。此说明不修改冻结协议、评分义务或任何原报告。

公开执行记录只归一化字段名、状态标签和共同文件的逻辑路径；t04 的请求上下文字段按协调者实际 fork_turns=none 请求恢复，同时保留执行者对实际设置未知的说明。每条记录保留原执行 JSON 的 SHA256 和具体投影变动；报告正文未改。禁止额外读取与盲法仍是提示约束和自报，没有 OS 级访问审计。指导正文的临时快照不重分发。
