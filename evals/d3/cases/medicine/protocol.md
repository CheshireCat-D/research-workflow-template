# 合成研究方案 v1（结局生成前冻结）

对象是8家虚构社区站点中预先列出的64位合成参与者。研究支持项目与常规支持的差别，无真实临床用途。每个站点内所有参与者接受同一分配；站点按地区配成四对。每对在两种可能分配之间掷公平硬币，恰有一家接受 program。四次硬币独立；个人没有再次随机。

主要终点：分配后第30天的自报负担分数，范围0至20，分数越低越好。主要估计对象：这8家站点的平均项目效应，以站点等权；分析先计算每对 program 站点均值减 control 站点均值，再对四对等权平均。报告效应和不确定性，不以仅达到阈值为成功标准。无预设协变量调整、亚组或剔除。

每家站点人数在分配前已固定。数据保留全部64人，无失访、无交叉、无真实身份信息。第7天同尺度分数曾作为运营监测收集，但不是预设的主要或次要疗效终点。现有附件在揭盲后首次汇总，未另行冻结任何终点变更。

材料只覆盖这一地点集合和一轮随访；没有其他疾病结局、安全性收集或外部推广数据。
