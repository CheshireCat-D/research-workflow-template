# 委托：两段效果表述的估量与识别审计

我在写一份方法札记，里面有两个相互独立的小例子。请分别处理 `medical-strata.csv` 和 `policy-periods.csv`，阅读 `design-note.md` 中的来源与草稿表述，先写清问题，再实际算出可核对的估量并修订短稿。不要把两份数据合并成一个效果。

医疗例子请计算各治疗组的总样本数、事件比例和粗风险差；再计算每个严重程度层内的比例与风险差，并按两组合并后的严重程度分布作直接标准化。政策例子请报告A镇2023到2024的前后变化、同期B镇变化以及两者差，再用2022—2023检查已有趋势，并报告将结局期换成2025时的相应差异。说明每个数的单位和目标对象，区分数值估量与需要额外依据的解释。

请离线用标准库写 `artifacts/run.py`，实际运行并保存 `artifacts/results.json`、输入指纹、参数、环境、耗时和失败。单次运行不超过10秒，不联网、不安装依赖。数据全部为新写合成汇总，不是真实医疗建议或政策效果评价，也没有已建立的新颖性或真实发表记录。
