# 两个独立的合成设计说明 v1

## M：观察性医疗汇总

M1 `medical-strata.csv` 的 `event_count` 表示30日内达到预先记录的恢复指标人数，`n`是该单元的主体数；每人只在一格中。治疗并非随机分配。严重程度会影响治疗选择，也与恢复有关；表中只有“轻”“重”两个粗层。未记录更详细的预后、偏好、转诊和测量误差信息。

M2 作者原句：“接受方案的恢复比例明显较高，已经说明方案有效；粗差可作为所有患者的治疗获益。” 这里只提供汇总计数，没有提供个体资料、随机化记录、伦理批准文件或未测混杂的检验依据。

## P：政策时期指标

P1 `policy-periods.csv` 的值是虚构的机会指数，单位为指数点，不是个体概率或百分数。A镇自2024年实施项目，B镇未实施该项目。年份为年度汇总，表中没有个体样本量或指数方差。

P2 同期存在其他变化：A镇2024年有工厂扩张，并开始把线上岗位纳入指数；B镇从2025年才纳入线上岗位。两镇在实施前的经济结构也未被视为相同。没有随机分配或政策实施以外的识别设计记录。

P3 作者原句：“A镇政策后指数上升，因此政策造成了全部增幅；加上B镇作比较便已自动消除混杂。” 本次需核对文字与表中实际可支持内容。

全部表值与情境均由本案例作者新写；M和P不是同一人群或可互相补证的研究。
