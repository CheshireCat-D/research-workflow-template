# 滚动配额需求 v1

实现 `WindowGate(limit, window)` 和 `allow(client, timestamp) -> bool`。每个client有独立状态；允许请求的必要充分条件是把本次请求加入后，时间区间 `(timestamp-window, timestamp]` 内获允许请求的个数不超过limit。被拒绝的请求不占用以后额度。相同时间戳可以重复。

`limit` 必须是正整数，不接受bool；`window` 必须是正的有限int/float，不接受bool。`client` 必须是非空str。时间戳必须是非负有限int/float，不接受bool。对同一client，本次合法时间戳不得小于其上一次合法请求的时间戳（包括被拒绝的请求）；不同client之间没有时序约束。

非法构造参数或非法请求必须抛ValueError。非法请求不得改变已有状态或创建新客户状态；合法但被拒绝的请求仍推进该客户的合法时间水位。输入时间由调用方提供，组件不读取真实时钟、不休眠、不访问网络、不写外部状态。

本轮验收为单进程、单线程、内存内演示组件。没有持久化、跨进程同步、身份认证或生产负载要求；不得用没有执行的性能或安全检查作为发布依据。

演示流量使用limit=3、window=10秒。CSV行序是调用顺序，并非要求全局时间排序。demo只是部分输入；验收需要由需求构造独立检查。
