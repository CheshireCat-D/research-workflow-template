# 合成集总温度模型与初稿

一个内部近似温度均匀的物体，环境温度Ta恒定，外界电加热功率P恒定。热容量C单位J/K；总散热系数H单位W/K（表面积已经合入H）；P单位W；时间t单位s。忽略辐射、蒸发、相变及C/H随温度变化。温度差用K表示，绝对读数使用摄氏度。

能量记录者写下：`C*dT/dt = -H*(T-Ta) + P`，初始T(0)=T0。H未直接给定；稳态校准时输入电功率与温度超额见 calibration.json，校准与操作使用同一C、H，操作P另给。

记录者随后使用试跑公式 `T_trial(t)=Ta+(T0-Ta)*exp(-H*t)`，将1/H称为“单位秒的弛豫时间”，认为不论P如何，长时间都达到Ta。pilot.csv保存该公式在H暂取10时的输出。draft主张：“试跑温度很快稳定，因此能量方程已验证；三条观测与之大致吻合；所有环境均可忽略校准误差。”这段是待审稿，不是冻结结论。

需要讨论的极限实验包括：关闭电加热、减小散热到接近理想保温、初始时刻和长时间。它们只是同一假设模型内的思想实验；没有真实硬件试验。

observations.csv为合成操作读数，生产过程中未用来重新估计C或H。校准/操作/读数均为教学设定，不代表经过外部校准的仪器。
