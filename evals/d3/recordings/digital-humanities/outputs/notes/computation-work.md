# 计算实际工作笔记

执行：`python3 artifacts/run.py`，标准库，未联网。实际 stdout/stderr/退出码/墙钟耗时在项目旁 `logs/05-analysis.json`；脚本内环境、参数、输入与代码 SHA-256、计时及失败在 `artifacts/results.json`；输入指纹另存 `artifacts/input-fingerprints.json`。确定性计数，不设随机种子。脚本以自身位置定位 PROJECT，可从其他 cwd 运行；相对数据路径随整个 PROJECT 移动。单次进程由日志包装器限制10秒。

规则逐字采用说明第3段：`re.findall(r"[a-z]+", text.lower())`；精确 token `liberty`，不做词干、同义合并和自动纠错；频率=100×词数/总token。缺失保留 null，不进入计数分母。汇总先求和再除，不平均各件频率。

手工基准先按原 token 串点数：D01 的五个 token 中第1、4为 liberty，2/5×100=40；D02 两个 OCR 错拼各不是目标词，0/4=0；给定修订为2/4×100=50；D06 为 liberty/liberal/tax，1/3×100≈33.3333。与脚本逐件输出一致。再用独立算式检查1900 OCR=2/(5+4)、修订=(2+2)/(5+4)，1910=(3+4+1)/(5+5+3)；E1的1910仅D04=3/5。不是用CLI通过替代数值核对。

全可用时期差为 OCR 39.3162 个每百token频率单位，修订后17.0940；E1分别37.7778与15.5556。D02修订将1900频率提高22.2222单位，差值因此缩小同样幅度。E1修订后仍有15.5556单位差，不支持“所有差都来自OCR”也不说明真实观念变化。按全可用改成E1后，1910频率61.5385→60，1900不变：这是现有材料子集的敏感性比较，没有版次因果效应的识别。
