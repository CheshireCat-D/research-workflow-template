# 合成加热模型的有界核查

在单一均温节点、C>0、H≥0、恒定环境和功率的假设下，内能变化率等于输入减散热：C T′=P−H(T−Ta)。两端单位均为W。指数必须无量纲，故试跑的exp(−Ht)缺少C；1/H的单位为K/W，不能称为秒。

稳态校准Qc=HD给出H=10±0.539 W/K；C=500±10 J/K为另给输入，不能由单个稳态点识别。正确解为

T(t)=Ta+P/H+(T0−Ta−P/H)exp(−Ht/C)。

因此τ=C/H=50±2.872 s，操作稳态为26±0.452℃。这些±是一阶标准不确定度。对独立基础输入(C,Qc,D,P,Ta,T0)求梯度传播，重复出现的H及环境温度使用同一变量；完整跨时刻协方差保存在结果中。τ与P/H相关系数约0.896，不能独立重抽。

在t=0、1、5、20、50、100 s，预测温度为80.000、78.931、74.861、62.197、45.865、33.308℃；对应u为0.200、0.207、0.360、0.948、1.351、1.139 K。三个非初始观测为62.2、45.9、33.4℃，残差不超过0.092 K；试跑对应均为20℃，偏差达13.4—42.2 K。观测未参与估参。初值吻合本身不验证动力学。

关闭加热后，解按50 s时间尺度趋向Ta；固定有限时间令H→0，解趋于T0+Pt/C，100 s为92℃。固定H>0的长时间极限是Ta+P/H，初始斜率是−1.08 K/s。试跑遗漏功率，无法满足有加热的平衡及理想保温极限。

一阶传播适用于给定局部小误差，不含模型缺失、时间误差或环境漂移。合成读数支持本模型在所给点的数值相容性，不能确认辐射等机理可忽略，也不能推出所有环境的校准误差均可忽略。本工作没有真实设备或安全认证。
