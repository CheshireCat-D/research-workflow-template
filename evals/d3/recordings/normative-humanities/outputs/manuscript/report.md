# 降温服务不应默认以实名手机为门槛

本轮应撤下拒绝实名手机登记者不得入场的规则。500次到访增至610次，混合了延时、预约与热浪；16名预约用户偏好手机，也不代表未注册居民赞同强制实名。零急救不能证明风险已消除（F1、F2、F4）。这些事实连效果判断都不足，更不能独自推出应当索取姓名、住址和亲属资料。

我采纳一个可被反驳的原则：基本降温服务的普遍身份门槛，应说明所防止的具体伤害、最低资料需求及较少负担的替代为何不足。理由是错误拒入会使基本保护落空，而预约便利可部分通过自愿方式保留。N1的匿名负担与N2的实际需要支持这一取向；它们是可争辩的价值理由，不是法律或多数授权。当前材料未证明统一门槛的必要性，因此支持匿名现场进入为默认。按现有40座建议计数与限流，自愿联系方式及紧急时最少必要询问可保留；容量满员仍可限制进入，40人也非安全认证。

最强异议是：先到先得可能让无法等待、行动不便者承受更多伤害。N2承认预约可能减少排队，N3重视秩序及联络。600的系统加500的电话协助，可能比1600的延时更公平。这一理由击中了匿名不等于可及的弱点；若等待是主要障碍、辅助预约确能覆盖被排除者，我会支持该竞争方案。但现有调查没有未注册者，也未比较等待与拒入，故尚不能据此购买系统，更不能要求全套实名资料。

预算选择须同时尊重工作人员。若核实新增时段填补基本降温缺口，且1600足以支付明确排班，我建议本轮先保留1600给该时段，余400暂留应急；延时加电话已需2100，不能声称兼得，也不得要求现员无偿补足。该条件未证实前，维持既有有偿服务，暂缓新增时段与采购。选择可能损失预约便利；若主要问题是排队，应重比1100的竞争方案并核算其额外人力。下一步应核实各时段未满足需要、未注册者障碍和排班成本。这里辩护的是有限默认及可改变的预算条件，而非已证明最优的现实政策。
