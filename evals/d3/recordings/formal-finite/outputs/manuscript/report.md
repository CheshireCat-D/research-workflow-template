# 一个整数多项式的有限素数段与无穷反例

令q(n)=n²−n+17，n为非负整数。原稿声称所有q(n)均为素数，但q(17)=289=17²已反驳该全称命题。差分q(n+1)−q(n)=2n只保证奇偶性相同，不能保持素性：q(16)=257为素数，其后加32得到合数289。

可以保留更精确的命题：q(n)在0≤n≤16均为素数，而且这是从0起的最长连续素数段。证明如下。该段内17≤q(n)≤257<17²。合数必有不超过其平方根的素因子，因而这里只需排除2、3、5、7、11、13。q(n)总为奇数。对其余各p，由4q(n)=(2n−1)²+67可知，p整除q(n)将使−67成为模p平方剩余；但其模3、5、7、11、13的值依次为2、3、3、10、11，逐一列举平方剩余均不可得。因此所需小素因子不存在，素性成立；n=17随即中断该段。

还可证明无穷反例族。对k≥1，

q(17k)=17(17k²−k+1)，
q(17k+1)=17(17k²+k+1)。

括号分别至少为17和19，故均为合数。n=0、1对应k=0，值为素数17，是必须保留的例外。排除这两个余数类并不保证素性，例如q(21)=437=19×23。
