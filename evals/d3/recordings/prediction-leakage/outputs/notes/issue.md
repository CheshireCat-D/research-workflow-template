# 问题与分析边界

拟议用途为首次接触、训练时未见的新主体，在day0预测90日结局。本练习可回答：同一固定记忆模型L在记录切分R和主体隔离切分S下，对给定12个合成主体的评估分别度量什么？所求量为主体等权的准确率、Brier、平均预测和事件比例及固定分箱表。

输入只有任务、模型卡v1、作者待修订段落和24条合成记录。每主体day0/day7各一行，共用一个event90；只有Synth-A、2024一个机构时间窗。不存在真实患者、临床试验、额外验证或外部随访队列。独立分析单位是主体，不能把重复行变为新病例。

模型、R/S切分、p>=0.5阈值及四个概率箱均由卡片固定，无调参或验证队列。正式运行前保存artifacts/config.json；执行者已读过原始输入，因此不称为盲态分析或前瞻性预注册。研究问题、模型与用途已有明确设定，无需新增候选选题。

主要待查义务：核对主体标签一致性、行唯一性和缺失；逐主体隔离情况；训练事件比例按不同主体；测试预测先按主体求均值；空校准箱保存null。R是否只恢复训练中已知的同一90日结局？S对训练未见主体是否退化为同一个基础率？全局均值吻合是否足够支持全风险段校准？本数据无法回答真正临床受益或跨机构适用性。
