# 同一主体重复记录如何改变预测评估

本合成练习比较固定模型L在两种切分下的表现，关注首次接触的新主体。24行来自Synth-A、2024年的12个主体，每人day0/day7各一行并重复同一90日结局；没有缺失、排除或不一致标签。模型仅保存训练主体结局，遇到新编号即输出训练主体事件比例；阈值固定为p≥0.5。模型、切分及分箱由卡片规定，无调参、另设验证集或结果驱动选择。正式运行前保存配置，Python标准库确定性执行，无随机种子。
