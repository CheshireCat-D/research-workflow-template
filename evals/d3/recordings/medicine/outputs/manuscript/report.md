# 配对集群随机合成研究的方法复核

本札记复核8个虚构社区站点、64名合成参与者的一次研究。站点按地区配成4对，每对公平随机选择1站接受项目；个人未独立随机。依结局生成前冻结的方案，以第30天0至20分自报负担为主要终点，低分较好；先求每对项目站与对照站均值之差，再对4对等权平均。全部站点和参与者纳入，结局完整，无调整或剔除。

第30天4对差依次为1、−1、2、0分，等权主要估计为+0.50分；项目与对照的等权站点均值为10.00与9.50分。在任何站点/参与者均无效应的尖锐零假设下，枚举16种合法配对分配，双侧精确随机化检验p=0.75。该检验处理真实分配层级，不能解释为效应为零的概率，亦不证明等效。

直接按个人合并时，项目均值9.00、对照10.75，差−1.75分，与预设估计方向相反。原因是两组不同负担站点的人数权重不同；64人并不构成64次独立随机化，也不能保证窄区间。

第7天等权配对差为−2.00分，双侧随机化p=0.125。该指标原为运营监测，在揭盲后才被挑选，既非预设主要也非次要疗效终点，只能作为探索性结果；不能替代第30天或单独隐去主要结果。

这4次独立配对随机化的不确定性较大。给定材料不能确认项目降低第30天负担，更不支持所有社区、真实患者、安全性或长期受益。分析只服务于所给合成站点的方法说明，站点及配对中间结果、全部随机分配和脚本另附，便于独立复算。
