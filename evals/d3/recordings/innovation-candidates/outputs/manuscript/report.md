# 历史辅助总和估计的收益与失配代价

我们研究旧向量与历史分数免费、当前值每读一次收费时的总和估计。材料仅为六个合成向量，N=12，预算k=4或6。已知均匀不放回差值估计A作为基线；本地笔记K1已经覆盖该原理，故删除草稿中的首创声明。大型预训练路线缺数据许可和GPU资源，本次不实施，也不声称误差优越。

令d_i=x_i−y_i，历史分数和为S。最初机制令q_i=s_i/S（S=0时均匀），p_i=1/(2N)+q_i/2，独立有放回抽k次，估计Σy_i+k^{-1}Σd_I/p_I。概率在读取当前值之前固定；重复也收费。它无偏，MSE=[Σd_i²/p_i−(Σd_i)²]/k。但在历史零分处出现新尖峰时，k=4/6的MSE为828/552，A为288/144；保底探索没有给出一致优势。

因此修订为历史正分H与零分L两层，预算各半、层内均匀不放回，估计Σy_i+Σ_g(N_g/k_g)Σ_{i∈S_g}d_i。本次层大小4与8，分配为(2,2)或(3,3)。各层差值估计无偏，独立层的方差相加。全场景结果见notes/results.md：carryover中A的MSE为176.545/88.273，修订方法为43.667/14.556；signed_carryover也改善。diffuse与quiet均打平；new_hotspot变差至432/240，shifted_pair也较差。

程序用解析有理数矩评估随机化误差，并枚举A及分层方案全部样本集合复核；每条件另运行1000次计费审计。48个比较条件在一秒内完成。有限结果支持历史匹配时的条件收益，并否定草稿的任意向量严格优势；不构成真实数据泛化或全球新颖性依据。下一步是在明确历史校准假设下推导固定分配的最坏风险界。
