# 问题卡与方法选择

当前问题：历史分数免费、每次当前位置读取都收费时，历史辅助抽样在哪些给定场景能降低均方误差？失配时付出什么代价？对象为 inputs/workloads.json 的六个 N=12 固定向量、预算 k∈{4,6}；不推断真实传感器表现。

资料范围：已全文读取 inputs/task.md、candidates.json、known-results.md、workloads.json、draft.md。笔记 K1/K2 为本地教学性结果，K3 明确不保证历史有效；无外部文献检索，全球新颖性未知。

方法：用 formal-theory 0.1 的 proof 分支手工推导有限概率空间中的无偏性与方差；用 computational 0.1 的 empirical-algorithm 分支执行全场景比较。没有形式化证明器。选择项目内 rw-question、rw-innovation、rw-candidates、rw-validation、rw-writing、rw-review；项目内安装不等于这些步骤已经完成。

先固定候选 C_mix：S=Σs_i>0 时 q_i=s_i/S，否则 q_i=1/N；α=1/2，p_i=(1−α)/N+αq_i；独立有放回抽 k 次，估计旧总和加 k^{-1}Σd_I/p_I。概率仅由历史确定；每次重复也付一次费用。最小反驳检查：只在历史零分位置发生尖峰，比较 MSE 与 A。若失败，删除一致优越保证，研究无放回分层修订。

预算一致的基线 A 为均匀不放回差值估计。B 需要未获数据与 8 GPU×72h，超出本任务离线 CPU 资源；只能比较可行性，不能捏造 B 的误差。

正式比较预定保留 A 与修订 C：C_strata 将 s_i>0 的位置分 H、其余分 L；k_H=min(|H|,max(1,⌊k/2⌋))，k_L=k−k_H，若超过 |L| 则将余额转 H；两层非空时保证各至少一次，层内独立均匀不放回。只有单层时退化为 A。全给定场景 H=4,L=8，分配为 (2,2)/(3,3)。该修订仅针对重复访问和常数变化的缺陷，不预设全局优越。

数值评价：以固定向量下抽样随机性为概率空间，解析 MSE 为主要终点；A、C_strata 枚举全部样本集合独立复核；C_mix 用单次抽样的全12点矩及独立平均公式。固定种子8123的1000次重复仅验证预算执行、记录实现与解析结果的相容性；不把一个样本或模拟胜率当作期望 MSE。所有完整当前向量仅在实验驱动的真值/误差/矩模块使用。估计器只能接收旧值、历史、计数访问器和抽样计划。
