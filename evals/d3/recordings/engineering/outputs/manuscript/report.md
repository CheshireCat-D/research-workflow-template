# 滚动配额组件的离线修复与有限验收

本组件面向单进程、单线程、内存演示。接口 WindowGate(limit,window) 按客户独立计数，仅当加入本次请求后区间 (t-window,t] 内获允许请求不超过 limit 才允许。拒绝不占额度，但推进合法时间水位；非法输入须抛 ValueError 且不改变状态。

先将需求转为可执行验收，再运行冻结原型。1578项中591项失败。最小反例是 limit=1、window=10 时，在0获准后10被误拒绝：删除条件将左端点保留。另有整数时间被 float 舍入、超大整数触发 OverflowError，违背允许有限 int 的合同。

修复将过期条件改为小于等于左端点，以 Fraction 精确保存输入数值，所有非法检查置于状态更新之前。保留每客户队列与合法时间水位，拒绝请求不入队。

同一验收复跑1578项全通过，正式计算约0.019秒；其中1512个非降时间轨迹与保存全部已允许历史、按定义计数的独立参考一致。其余检查覆盖重复时间、窗口端点、拒绝、客户隔离、非法参数和异常后状态。演示CSV亦按行序重放。原型失败、修复结果和输入指纹均已保存，实验确定性，种子不适用。

本次交付是有有限验收依据的本地组件。未执行生产负载、安全、持久化或并发验证；不能据此宣称可保护任意规模分布式服务。需扩大用途时应先明确共享状态与故障合同，再独立设计并验证。登记检查仅核对文件和引用一致性。
