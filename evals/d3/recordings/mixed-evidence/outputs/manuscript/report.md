# 跨机构服务研究：供团队讨论的短稿

本次只分析所供合成材料。可回答的是A的标签分类表现、B志愿者的流程完成变化，以及访谈如何限定这些结果。两机构并非共同样本，结局也不同。

A在2023年100人的既有记录上评估固定分类器：真实阳性40、阴性60。以真实标签为行、预测结果为列，混淆矩阵为[[32,8],[8,52]]。敏感度32/40=80%，特异度52/60=86.67%，阳性预测值32/40=80%，准确率84/100=84%（P1）。这些数值描述与标签的一致程度；训练评估独立性、校准及外部表现未核实，不能推出流程或生活获益。

B在2024年从13名符合联络条件者中招得8名志愿者，参与比例8/13。两周试点同8人的完成比例由2/8（25%）升至5/8（62.5%），增加37.5个百分点（P2）。没有逐人转变表，不能说恰好三人改善；五名未参加者结局未知。工具与提醒电话同时加入，无随机或同期对照，变化不能归因于工具。

I1.1提示分类之外仍有响应安排问题。I2.1描述个人完成与电话协助，也提示参加者原先较愿投入；其与P2样本重叠，不是独立效果复制。I3.1核对招募与新增提醒信息。I4.1—I4.2提示提醒安排对一名未参加者存在适配障碍；这里只作概括，遵守不直接引用原话的条件。节录不代表总体，也不证明饱和。

三类资料没有共同检验“同一工具造成跨机构普遍获益”。分类与完成的差异主要来自对象、地点、时间和测量差异；访谈提供互补解释和反向个案。可保留的局部连接是B确有完成者，其经验与汇总相容；仍未连接分类到响应和完成的过程。

最有价值的下一步是核对A/B工具与输出身份，按同一结局建立“分类输出—回应动作—完成”的可追溯连接表，标明提醒及参与选择。没有共同构念时维持分层问题；有连接依据后再设计比较。本稿是研究方法练习，不作服务或临床实施建议。
