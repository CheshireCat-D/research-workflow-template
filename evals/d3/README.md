# 方法、创新与跨学科回归素材

本目录保存当前回归测试所用的16项离线合成任务与实际产物，覆盖八个技能、九类方法与六类学科语境。原有16个架构场景的映射在 [coverage.json](coverage.json)；其中史料场景沿用已独立复核的 [基础任务](../d2/README.md)，其余由本目录任务对应。实现、任务执行和内容审阅分别记录，不以文件数量或关键词命中替代行为验证。

## 材料、产物与审阅

- `cases/` 是执行前冻结的原始任务和输入。执行者只取得自己的任务、材料及模板技能，没有评分笔记或其他任务答案。
- `recordings/CASE/outputs/` 保存实际推导、分析、代码、结果、短稿和审阅。`recording.json` 引用原始输入，不重复分发；规范化重放创建新项目与版本为1的最终记录，不重建原过程所有历史。
- `execution-summary.json` 保留实际错误、失败、限制和日志索引。原命令日志与安装运行时留在隔离执行目录，不重复进入发布包；有路径替换的非科学元数据会列出原指纹与转换。
- 内容审阅由未参与该项执行的代理根据原始材料独立复核，程序在另建副本中重跑，原项目只读。代理审阅与人类专业同行评审不同，具体范围由每项证据声明。

任务包括创新与候选对抗、医学随机干预、农业区组及跨季重复、预测验证、观察与政策识别、定性分析、规范论证、有限证据综合、工程原型与物理仿真、模型校准、混合证据、数字人文、材料外发权限与有限检验的证明边界。`d3` 是保留的素材组标识，不是软件版本；目录不包含另一套旧软件。每种方法的真实变体远多于这些代表性任务；模板只报告实际执行的范围。

## 发现问题时如何处理

执行过程中的错误和独立审阅缺陷都保留。修订由原执行者核对原始材料后进行，旧版置于隔离修订记录，用CLI显式替换有关证据／产物／评估，再复核依赖活动并保存新检查点。最终发布快照取实际修订后的状态；不能将待修订的案例先标为通过。

例如，本轮发现医学工作笔记的次要合并均值与正确结果文件不一致，以及定性编码将代理执行误称为人类编码；两项均在保留原记录后修正并另行复核。跨季农业还补入由实际同级日志生成的项目内执行凭据，保留原未记录信息并重新绑定；同级日志原安排符合任务要求。研究内容、执行者身份、程序检查和独立内容审阅各自报告，不以文风或登记通过代替。

## 可重复检查与范围

`tests/test_d3_evaluations.py` 用当前技能副本重建所有登记，检查只读恢复及独立审阅所绑定的输入／产物指纹，并按明确计划重跑实际代码的科学结果字段。自动回归不调用模型，也不重新产生一次独立评审。数学、解释性与规范性判断仍需阅读材料和论证；字段或哈希一致只证明版本身份。

从仓库根运行 `python3 -B tools/check_core.py`。当前软件检查与发行状态以[当前核验记录](../current/latest.json)和[发布验收](../../docs/10-release-readiness.md)为准；当前16例均在限定范围内通过独立代理复核；输入与发布产物指纹绑定见 [independent-review.json](independent-review.json)。这不表示人类专家认证或所有方法变体已测。
