# 问题卡与本轮范围

本项目是离线虚构档案练习；无真实史实、私人资料、发表史或新颖性判断。作者日期为1912—1938年的材料身份，均来自案例的虚构编目，不代表已验证真实原件。

当前问题：仅据 `inputs/archive-packet.md` 的H1—H7节录和 `inputs/inventory.csv`，能把1912年9月16日东埠夜校停课写成什么性质的事件？经费、夜航中断与出席变化分别能解释哪一环？原草稿 `inputs/draft.md` 的唯一原因、永久停办、先停发全部津贴和捐助必能避免停办，有无支持？

分问题：

1. 时间：8月财务记录、9月5日起停夜航、9月6日起所见出席下降、11日议定安排、18日对16日停课的追述之间，哪些是直接记载，哪些只是推断？
2. 原因：把经费视为唯一原因、把通行困难视为近期触发、或把两者视为可能并存的约束，何种解释较能容纳材料？
3. 来源：H3、H4、H5是否同一传播链？H6是否亲历1912年？H1与H7能够独立支持到哪一步？
4. 确定程度：如何区分拟停六周、实际开始停课、实际停课期限与永久停办？哪些后续材料能改变现有排序？

边界：已逐字读取所供七份节录、全部编目及草稿；没有完整账簿、会议簿及签名页、发信原件、报刊全页、完整布告、回忆录音或全套点名册。不外查，不补造档案，不把编目当正文，也不将材料条数换算成支持票数。日期均按给定书写，不自行校正H1“本月十五”。
