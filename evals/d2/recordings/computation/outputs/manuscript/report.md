# 固定求值预算下两种复合积分法的局部比较

本合成练习比较附件六个函数在 [0,1] 上的绝对积分误差。原试跑的四行数值均可复现，但中点法用了128次求值，梯形法只用9次，不能支持同资源比较；试跑也没有速度证据。

正式预算为9、33、129次函数调用。保持附件算法不变，中点法取 n=B，梯形法取 n=B−1，每项实测调用数均等于B。参考值使用附件给定积分表达式，以Python标准库双精度实现；原函数核对和18个常数、线性、二次基准均通过。全部36项成功，总计2052次正式求值。

预算为9时，中点法在四个目标上误差较小，梯形法在振荡和折点目标上较小。对 cos(18πx)，中点采样发生混叠，误差为1，梯形法误差约1.67×10⁻¹⁶；折点目标误差分别为0.001344和0.000600。六目标等权平均误差因此为0.16755和0.002341，中点法较大。

预算为33和129时，中点法各在五个目标上较准；振荡目标两法误差差值不超过预设的10⁻¹²，视为浮点尺度内并列。两档平均误差，中点法分别为8.13×10⁻⁵、9.03×10⁻⁶，梯形法为2.58×10⁻⁴、2.91×10⁻⁵。逐目标结果保存在 `artifacts/summary.csv`，原始参考值、调用计数和配置见 `artifacts/results.json`。

CPython 3.14.6、macOS arm64上的正式进程墙钟约0.065秒，满足10秒限制；此计时不用于比较速度。无随机过程，种子不适用。迁移后复跑的数值与调用数完全相同。本结果只覆盖六个目标、三档预算与双精度实现，参考值没有认证舍入界；不能推出任意函数上的普遍优越、一般收敛阶或速度排名。
