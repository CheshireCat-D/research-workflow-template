# 问题卡与预先比较计划

本案是新写的合成练习，不含私人数据、真实发表记录或新颖性结论。材料以 `inputs/` 中保存的原始字节为准；本次不联网、不安装依赖。

**问题。** 在 [0,1] 上，附件六个目标、三档函数求值预算 B∈{9,33,129} 下，固定复合中点法和梯形法的绝对积分误差如何变化？哪个方法在哪些目标与预算下更小，是否出现足以推翻“全面超越”的反向结果？问题能由 36 个确定性算例回答，并能纠正稿件的预算混淆；它是有限复核，不是开放问题或新方法。

**材料审计。** `methods.py` 的 n 是子区间数；中点法调用 f 共 n 次，梯形法共 n+1 次，没有缓存或自适应。`pilot.csv` 只有二次、指数两目标，用中点法 n=128（128 次求值）对梯形法 n=8（9 次），并非相同资源。一次运行次数相同不等于求值预算相同；表中没有时间数据。试跑只可能描述这四行的数值，不能推出所有函数、预算、速度或推荐范围。脚本将逐行重算试跑并保留偏差。`draft.md` 的同资源、普遍优越和速度三项论断均须依据正式结果改写。

**预算口径（在正式运行前确定）。** 每次调用被积函数算一次，不缓存端点、不共享跨目标或预算的结果；中点法令 n=B，梯形法令 n=B−1。两者均恰好耗尽 B 次预算。用包装函数实测计数；参考值计算、基准和试跑复核不计入单个正式积分预算，另行列明。不得改算法公式、删目标或只报告有利单元格。正式输出保留全部 6×3×2=36 行。

**参考值与独立核对。** 数学表达式来自 `targets.json`，不用待测算法产生参考。逐项手工核对原函数：x²→x³/3；exp(x)→exp(x)；√x→2x^(3/2)/3；cos(18πx)→sin(18πx)/(18π)，两端为零；|x−a| 在 a=37/100 处分段积分得 (a²+(1−a)²)/2；1/(1+25x²)→atan(5x)/5。按附件要求用 Python `math`/双精度实现这些式子，在结果中保留表达式、十进制与 float.hex 值。真值表达式是数学值，计算的是其双精度近似；不声称参考值有认证误差界。振荡函数的 π、三角函数和 kink 的 0.37 也有浮点误差，接近机器精度的差别不解释为方法优势。

正式比较前，独立验证常数、线性函数的积分，以及 x² 的闭式离散和：M_n=1/3−1/(12n²)，T_n=1/3+1/(6n²)。这来自等差平方求和，独立于待测算法输出。对三档预算共做 18 个基准，容差 1e−13，并核对调用数；失败则停止正式比较并报告失败。

**汇总及判据。** 原始误差为 |估计−参考近似|。每预算保留逐目标表，并报告六目标等权平均、误差中位数与最大值；这些描述量不代表目标总体分布。不使用显著性检验。比较两法误差差值≤1e−12 时标记“浮点尺度内并列”（预设绝对阈值），严格数值大小也保留。三档预算提供有限敏感性检查，不能据三点宣称一般收敛阶。

**执行条件。** 仅 Python 标准库，确定性、随机种子不适用；记录 Python、平台、CPU/墙钟时间、可见资源限制与失败/非有限行。正式子进程外部墙钟上限 10 秒；脚本尝试设 CPU 软/硬限 8/9 秒并记录是否成功；未额外施加内存硬限。一次短时计时只核查约束，不比较速度。若出现失败不删行，输出异常及已发生调用数。

**最小下一项检查。** 完成全部预算后，检查振荡目标是否发生采样混叠，以及折点目标的方向是否随预算改变；据此决定是否只能保留局部优劣结论。正式运行后另存审阅和修订稿。项目迁移复跑将写到项目外新目录，保留正式文件不变。
