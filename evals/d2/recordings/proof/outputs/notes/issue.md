# 问题卡：零积分可以确定什么？

版本：讨论稿 v1；只使用 `inputs/` 的合成材料与在本文展开的基础数学推导。

## 细化问题

固定 Lebesgue 测度空间 ([0,1], μ)，对有限值非负可测函数 f，问：

1. 积分为零是否等价于 f 几乎处处为零？它是否规定已选代表元在任意固定点的值？
2. 若 L1 指等价类，与指已选可积函数时，准确结论分别怎样写？
3. 草稿的“存在正值点 ⇒ 邻域有正下界”需要什么新增条件，端点是否包括？
4. 附件的有限网格究竟支持什么，能否判断未知 F 的积分或逐点值？

保留前三项作数学主线，第四项作证据边界检查。这是基础分析练习与草稿修订；不作研究新颖性或真实文献覆盖判断。

## 方法、最小检查与范围

采用 formal-theory / proof：先用单点指示函数直接否定逐点结论；再以正水平集证明可保留的等价命题；解释等价类；在原条件后新增连续性并证明逐点修复。独立复核采用反向检查每个量词和积分比较、直接检查反例假设，以及用零点稠密性重证连续性修复。

网格只做格式、精确记录值与有限性复核；另构造与同一网格一致而积分不同的函数，作为采样推断失败的数学证据。不把运行脚本或 CLI 成功当成证明。

交付不包含外部检索、真实文献认证、数值误差估计、未知 F 的识别或机器形式化证明。保存的下一步是讨论采用“已选代表元”还是“L1 等价类”的记号；若坚持逐点结论，必须明确保留新增的连续性条件。
