# 练习项目委托：零积分命题的修订

我在写一页分析课的研究札记。合作者给出了 `draft.md`，并用 `observations.csv` 的网格记录作了补充检查；本地可用的基础文献摘记是 `source-notes.md`。请从这些材料开始，帮我把值得保留的问题说清楚，判断草稿命题与论证的适用范围，完成必要的数学工作，再给我一份可供讨论的短稿。

我的原始问题是：在草稿所写的条件下，零积分究竟能确定函数的哪些性质？“L1”这一记号是否影响原命题的表述？如果原论证需要修订，请给出准确命题、完整理由及必要的限制；如需补充条件，请明确新增条件的位置。请独立复核自己的数学结果。不要仅转述摘记，也不要把网格记录当作已经完成的数学工作。

请离线执行，只使用所附材料和基础数学推导；不需要搜索真实文献或声称研究新颖性。将交付物写入你自己新建的隔离临时项目 `PROJECT`（新建于系统临时目录，目录名自定），不得把案例输入目录当项目根目录，也不要修改输入。

需要留下：

- `notes/issue.md`：细化后的问题、材料定位、采用的方法与工作范围。
- `notes/work.md`：实际推导、原稿审计与独立复核过程，区分推导和观察。
- `manuscript/report.md`：不超过500词等量篇幅的中文短稿（约1000汉字以内，公式不计），供数学讨论使用。
- `review.md`：短稿审阅，写明已核查内容、仍有的限制及具体下一步。
- 用当前模板的 D1 CLI `tools/research.py` 初始化这个项目，登记来源、关键主张、证据、支持关系和实际活动；把项目内材料与产物用相对路径追溯。保存 checkpoint，并实际运行 `check` 与 `resume`，将两份输出保存在项目旁的临时目录中。最终回复提供项目绝对路径、主要文件路径和保存的下一步。CLI只核查其声明的范围，请按实际状态登记研究结果。

来源声明：本案例所有文字、摘记与网格记录均为新写的合成材料，不含真实个人资料；没有已建立的真实发表记录或新颖性结论。
