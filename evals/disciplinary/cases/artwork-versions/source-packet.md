# 原创虚构画作与来源
所有图像和下文为本任务原创虚构，可MIT分发。作品名《两条路径》，虚构艺术家林序，虚构制作时间1901年。original.png是本任务原始构图；reproduction.png是1924年展览目录的裁剪复刻，裁掉原构图底部180像素，再等比放大。图像为几何风格，并非真实历史作品。
A1 创作者工作笺（1901-04，第2行）：我让门内和门外两条路在画面中相接，想保留观看者对去向的选择。该笺未提政治组织、工厂或集体抗议。
C1 展览目录（1924，第5段）：我们将画面上部放大，以强调墙面与门洞的几何张力。目录将作品读作封闭制度的象征。
E1 后出编者说明（1970，第8行）：该画没有人物，因此作者必在谴责工业劳动制度。这段判断只依据1924年复刻，未查原构图或工作笺。
原图在下方左侧有小型人形；门洞/道路等几何要素可直接从原图观察。最后一句是当前材料编写者对图像的导航描述，仍请自己查看并定位。
