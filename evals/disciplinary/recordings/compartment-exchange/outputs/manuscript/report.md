# 两室交换的解析与Euler结果

在每室1 L、无源无损失且瞬时混匀的条件下，浓度满足 a′=−k(a−b)、b′=k(a−b)，其中 k=0.5 h⁻¹。k(a−b)为浓度变化率，乘体积才是溶质量转移率。浓度用U/L、时间用小时，总量为12 U。

令s=a+b、d=a−b，则s′=0、d′=−2kd。由初值(10,2)得a=6+4e⁻ᵗ、b=6−4e⁻ᵗ（t取小时数值），两室均指数趋于6 U/L。t=0、0.5、1、2、4 h时，A浓度为10、8.426123、7.471518、6.541341、6.073263，B为12减相应值。取τ=2kt、u=a/6、v=b/6，则uτ=−(u−v)/2、vτ=(u−v)/2，u+v=2。

Euler守恒浓度和，其差值为8(1−h)ⁿ。步长0.25、1、1.5、2.5 h对应系数0.75、0、−0.5、−1.5：分别非交替收敛、一步到平衡、交替收敛和发散。2.5 h的第2步为(15,−3)，反驳任意正步长均非负。对所有非负初值，保非负需h≤2 h；差值渐近稳定需0<h<2 h；边界2 h仅周期交换。

固定终点4 h，将h由0.25减至0.015625，误差由0.033172降至0.002277 U/L，相邻误差比趋近2，与一阶推导一致。旧稿的线性降至零、任意步长非负及同速收敛主张均须修正。
