# 笼位随机化的2×2析因比较

本合成试验含3个区组，每区组4笼，区组内将笼随机分配至饲料F与环境E的四种组合，每笼测量2只动物。处理单位为笼，共12笼；每种组合有3笼、6条个体记录。个体记录用于计算笼均和描述笼内差异，24条记录不能视为24个独立处理重复。

按F0E0、F1E0、F0E1、F1E1排列，三个区组的笼均增重分别为(10,12,13,18)、(20,22,23,29)、(30,32,33,37)g；等权汇总为(20,22,23,28)g。差均定义为1减0。先在区组内计算，再平均，F与E的边际差分别为3.5g和4.5g。

交互对比(F1E1−F0E1)−(F1E0−F0E0)在三个区组分别为3、4、2g，平均3g。F在E0、E1下的平均差为2、5g；E在F0、F1下为3、6g。因此原稿的2g和3g只是相应基准条件下的简单差，不能代表边际差；交互为0及普遍相加的表述与本例不符。三个区组均出现正交互，大小有所变化。本例演示分配单位和析因对比，不据此宣称真实动物的普适效果；未产生真实动物操作或伦理审批记录。
