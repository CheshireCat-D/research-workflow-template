# 重复键查询：合同核对与操作计数

执行者为 Codex 代理；这是原创离线合成材料的确定性算法比较。依据为 inputs/contract.md、records.csv、queries.json；inputs/draft.md 保留原稿，manuscript/report.md 为其改写稿。使用 rw-validation、rw-writing、rw-review；engineering 0.1 规定软件比较需明确系统边界，computational 0.1 要求输入、基线、度量及实际命令可复查。本次绑定 empirical-algorithm 变体。

## 1. 同一查询功能

有序记录共8条、5个不同键，重复出现的额外记录为3条。a 的最后值是70（覆盖10、30），b 是50（覆盖20）；c、d、e 分别为40、60、80。任取一条重复键记录不满足合同。例如返回 a=10 即与 a=70 的要求冲突。

L 对每个查询从头到尾扫描8条，匹配时更新候选结果；I 按原顺序执行8次字典写入，使后写覆盖前写，再逐查询查找。两者不更改输入。独立核对使用从后向前首次匹配的参考实现，此参考只用于正确性核对，不加入两路线研究成本。

实际逐查询结果（artifacts/results.json 保存每个负载的完整轨迹）：

| 查询序号 | 键 | L返回 | I返回 |
|---|---|---:|---:|
|1|a|70|70|
|2|missing|null|null|
|3|b|50|50|
|4|c|40|40|
|5|a|70|70|
|6|e|80|80|
|7|d|60|60|
|8|missing|null|null|
|9|b|50|50|
|10|a|70|70|

10个给定查询全部相等，前1、2、10个负载的13次调用亦全部通过独立参考核对。输入运行前后 SHA-256 一致，原件与复制件 SHA-256 一致。

## 2. 同一负载的端到端合同成本

每一前缀视为独立冷启动负载，I 各自构建一次；不在三个负载间共享索引。设 n 为记录条数、m 为查询次数：C_L=nm，C_I=n+m。这里端到端指合同明确计入的全部逻辑工作：L 的逐记录键比较、I 的逐记录写入和逐查询查找。解析、校验、轨迹记录、内存分配及真实散列探测不在双方声明的模型中，因而不是所有机器指令的计数。

| 前缀m | L构建 | L查询 | L总成本 | I构建 | I查询 | I总成本 | L总/I总 |
|---:|---:|---:|---:|---:|---:|---:|---:|
|1|0|8|8|8|1|9|0.889|
|2|0|16|16|8|2|10|1.600|
|10|0|80|80|8|10|18|4.444|

因此单次查询时 I 的总成本更高；从本数据的两次查询开始，构建开销被摊薄，I 才具有较低总合同成本。代数条件为 nm>n+m，即 (n-1)m>n；n=8 时 m>8/7，最小整数为2。对任意有限正 m，8m/(8+m)<8，故原稿“所有负载至少快八倍”与该成本口径冲突。8只是忽略构建时的查询阶段操作数比，且也不是墙钟加速倍数。

## 3. 重复键、重复查询与未命中

重复键改变应返回的最后值，I虽只保留5个键，仍须写入全部8条，不能将构建成本写成5。L遇到较早匹配不能提前停止，否则会漏掉后续覆盖。

查询 a 出现3次，b 和 missing 各2次，合计4次超出首次出现的重复调用。两条路线均未缓存单个查询答案，每次调用照常计数；I在同一负载内共享一次构建好的索引。查询重复本身不提供免费查找，也不代表独立随机实验；增加调用次数使固定构建开销的每次查询摊销份额8/m下降。即使全部查询不同，当前模型下相同m仍得相同总成本。

第2、8次未命中返回null。L仍扫描8条，I仍做1次查找；两次未命中在10查询负载中分别贡献16次比较和2次查找。本合同下命中位置、命中率、重复键频率均不改变固定n、m下上述公式，但会改变输出及真实运行实现的行为。

## 4. 实际执行、失败与可重现范围

artifacts/run.py 只用标准库，接受 --input-dir DIR --output-dir NEW；从参数路径重读材料，输出目录必须尚不存在。已真实运行主计算及搬移代码和输入后的复算，results.json 字节完全相同；checks/computation.json 保存实际argv、退出码及输出。已有输出目录的负面检查返回2，原输出未被覆盖，该预期拒绝保留在日志中。主计算和搬移复算均退出0；未出现未解决的计算失败。

execution.json 记录输入、输出、代码 SHA-256、实际命令、指导路径；process duration 与机器信息另列，只证明执行完成的环境及耗时。没有单独计时两路线，也没有计时重复、统计速度或检验 Python 字典真实复杂度；结果是所给模型的确定性操作数。当前仅在这次 macOS/Python3.14 环境执行，标准库代码设计为可跨系统重跑，未将未运行平台记为通过。

复算示例：python3 artifacts/run.py --input-dir inputs --output-dir /新建结果目录。结果依赖合同语义的人工落实；更改 contract.md 后必须审阅实现是否仍符合合同，不能只靠重新散列确认科学正确性。
