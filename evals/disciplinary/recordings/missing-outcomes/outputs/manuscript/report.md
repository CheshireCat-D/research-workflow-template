# 第30天结局与失访敏感性

本合成随机试验每组分配10人，主要终点为第30天二元不良事件，比较方向为A减B。A组观察到8人，其中2人发生事件，另2人缺失；B组观察到9人，其中3人发生事件，另1人缺失。完整病例风险分别为25.0%和33.3%，风险差为−8.3个百分点。缺失结局未按无事件填补。

令a为A组两名缺失者中的事件数，b为B组一名缺失者中的事件数，则全体随机分配者的组别风险差为(2+a)/10−(3+b)/10。依次枚举(a,b)=(0,0)、(0,1)、(1,0)、(1,1)、(2,0)、(2,1)，得到−10、−20、0、−10、+10、0个百分点。

不对失访机制加假设时，A组风险范围为20%至40%，B组为30%至40%，风险差极端界限为−20至+10个百分点。若A组缺失者均发生事件而B组缺失者未发生事件，差值为+10个百分点，方向与完整病例结果相反；也存在两组相等的情形。这些界限反映未知结局的范围，并非置信区间。由于未提供失访机制证据，完整病例中的较低风险不能据此认定为全体随机分配者中稳定的风险降低。
