# 裁剪如何改变《两条路径》的观看

虚构画家林序的《两条路径》（1901）在原构图左下保留了小型人形，门洞下的两色道路向前景展开（original.png，左下及门洞下缘）。人物与建筑的尺度差，使去向问题落到具体观看位置。A1工作笺说要让门内外道路相接，保留观看者的选择（材料包第3行；所载1901-04第2行）。据此，把门洞读作未定的去向，有图像和自述的共同支持。

另一种读法强调阻隔：庞大墙面与幽暗门洞造成压力。1924年目录将其读为封闭制度，并说明放大上部以强调几何张力（包第4行；C1第5段）。复刻实际未见人形，大部分道路也被裁去，墙与门因而更突出（reproduction.png）。这种展陈解释有可见依据，但应归于1924年的观看语境；原图的道路相接与A1仍容许选择，门洞不只意味着封闭。

1970年E1仅据复刻认定原画无人，再推为艺术家必在谴责工业劳动制度（包第5行；E1第8行）。原图人形已挑战其前提，A1与C1也未确认这个具体对象。原构图、裁剪版本及后出解释须分开使用：选择与阻隔可以构成张力，后出的制度读法不能改写为已确认的唯一创作意图。
