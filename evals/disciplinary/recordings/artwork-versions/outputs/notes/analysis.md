# 《两条路径》：版本、视觉锚点与竞争解释

## 对象、方法与实际访问

本分析只处理所给原创虚构材料，不把林序、1901年作品或1924年展览当成真实历史事实。研究问题是：裁剪复刻改变了哪些可见依据，哪些解释可用于原构图、哪些应归于后来的展陈与接受？采用 historical-interpretive / art-interpretation（画像版本0.1），结合版本辨认、图像细读与来源层次对照。执行者是 Codex 代理；没有独立人类专家审阅。

已使用 `functions` 中的 `view_image` 实际查看原输入及项目 `inputs/` 复制件的 `original.png`、`reproduction.png`，不是只读文件名、图像导航文字或PNG头。两份输入图像各全图可见。还全文读取了输入包、单行草稿和任务说明。A1/C1/E1只取得材料包中的节录，没有取得独立工作笺、完整目录、编者说明原件或更多历史语境。

定位采用各文件自身像素坐标，原点左上；下列范围是看图后的近似定位，不冒充逐像素测量。

|---|---|---|---|

## 解释一：去向与观看者选择

支持：A1（材料包第3行；所载1901-04工作笺第2行）直接表述要让门内外道路相接、保留观看者对去向的选择。原图的路径相接、向前景展开及小型人形，提供“人在门前如何选择”的视觉锚点。这里人物是观看关系中的尺度与位置线索，不能断言其身份、行动目标或已作出的选择。

限制与挑战：门洞深暗、墙面庞大，开口不自动等于自由；道路的几何相接也没有给出真实可通行空间。A1支持艺术家所表达的一项创作考虑，但单段自述不穷尽作品意义，也不能证明所有观看者都会作同一理解。因此此读法对原构图与明确表达的创作考虑有较强支持，不是唯一答案。

## 解释二：阻隔与封闭制度

支持：大面积墙体、幽暗门洞和人物相对于建筑的微小尺度，可使观看者感到阻隔或压力。C1（包第4行；所载1924目录第5段）明确说明放大上部、强调几何张力，并将作品解释为封闭制度象征。复刻删掉人物及大部分路径，墙面与门洞占据画面的效果更突出；“封闭制度”作为1924年展陈读法有明确材料定位。

限制与挑战：原图的门洞仍是可辨开口，道路相接提供另一种方向关系；A1也保留选择。因此“封闭”可作为竞争解释或与选择并存的张力，不能从几何形式推到唯一象征。C1出自创作23年后的展陈语境，不能改署为艺术家1901年已确认的意图。作品内没有可识别的机器、工厂标识或政治组织标记；这些身份未知，不得凭暗门和墙面补入。

## E1的推断与证据不对称

E1（包第5行；所载1970编者说明第8行）把复刻中“没有人物”的观察扩展到原画，再推为艺术家必在谴责工业劳动制度。第一步受原图可见人形直接挑战；第二步把一般制度寓意收窄为工业劳动对象，没有对应视觉标记或A1/C1原文支持。E1是对后期复刻的解释，能用于研究1970年的接受表述，不能承担原构图描述或唯一创作意图的证明。

A1、C1、E1均由同一个合成材料包提供节录；三者日期、文类、对象与作用不同，不能合计成“三份独立一手证据”。E1明确仅依复刻、未查原构图和工作笺。它是否直接抄录C1未知，不能另造文本传承链；可确定的依赖是其可见范围受1924版本约束。

本次判断：对原构图与作者已表述的考虑，选择读法依据更直接；对1924年展陈效果，阻隔读法有材料支持。两者不是按票数平均的等强答案。E1的工业劳动“唯一意图”读法在本包范围内不成立。A1所给节录未提工厂或抗议，不足以反证艺术家从未有相关想法；结论是当前材料不能确认，而非证明政治意义不存在。

## 草稿逐项审查及处理

| 草稿定位：inputs/draft.md第1行 | 发现与依据 | 新稿处理 |

| “门洞只可能象征封闭” | 门洞开口、相接道路与A1均容许另一解释 | 保留选择与阻隔两条有锚点的解释，交代证据强弱 |
