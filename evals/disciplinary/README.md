# 七学科专项任务与回归

本组使用原创合成材料，实际执行分析、改稿、登记和恢复。它补充既有21项研究任务；原任务的输入、产物和独立审阅保持原样。

| 学科语境 | 任务与原始输入 | 本次专项 |
|---|---|---|
| 自然科学 | [两室交换](cases/compartment-exchange/task.md) | 解析解、无量纲化、守恒及离散稳定性/非负性 |
| 工程与计算机 | [索引构建成本](cases/index-build-cost/task.md) | 相同查询语义、重复键及端到端成本 |
| 医学与健康 | [失访结局](cases/missing-outcomes/task.md) | 分母、完整病例、无假设界限与敏感性枚举 |
| 农学与生命 | [析因动物试验](cases/factorial-animal/task.md) | 笼位随机化、两个因素的边际差与交互 |
| 社会科学 | [分层调查](cases/weighted-survey/task.md) | 设计加权、无应答调整及缺失界限 |
| 人文 | [画作与展陈版本](cases/artwork-versions/task.md) | 实际查看原图/裁剪图、来源层次及竞争解释 |
| 法学 | [多语法条](cases/legal-language-scope/task.md) | 共同权威文本、定义、连接词、例外与压缩保真 |

执行者只取得原任务、材料和所需当前指导；原始输入在执行前冻结。每项产物完成后，由未参与该项执行的代理对照材料复核。实际完成状态、输入和产物身份以同目录的覆盖与审阅记录为准。

数值和算法回归在新目录重跑实际代码，使用独立公式或计数核对关键量，并改变输入检查脚本是否真正读取材料。文本解释与法律论证由内容复核判断，不以关键词出现次数评分。工程回归另重建项目，核对只读恢复及输入变化引起的失效提示。

案例属于源码测试材料，精简用户包通过公开仓库链接查阅，不复制进每个研究项目或下载包。需要仿照案例开展自己的研究时，另建独立项目并使用自己的材料、权限和目标。

## 分发与重放

`recordings/CASE/recording.json`引用原输入和实际产物，保存最终登记及读取指导的身份；`observed-check.json`、`observed-resume.json`为维护者在原项目上实际执行的最终只读查询。自动重放重建新身份、版本为1的最终记录及检查点，不复演所有模型推理或完整修改历史。

公开材料只净化明示的机器路径；每项变化保留原始与分发指纹。未登记、与规范结果逐字节相同的复跑结果只保留规范文件及去重映射。研究代码、规范结果和短稿不作这类改写；实际失败、语义更正与代码边界修复的证据仍保留。

操作日志按用途保留：每例的 `outputs/execution.json` 保存执行事件、命令和退出状态，最终状态由登记及 `observed-check.json`、`observed-resume.json` 保存。空日志、重复输入副本和未登记的成功操作快照已从分发目录移除；每例 `recording.json` 的 `distribution_projection` 列出省略项、原因和保留位置，使用 `output:`、`recording:`、`case:` 分别定位该例的输出、记录目录和原始输入。历史收据中的路径可通过这份映射查找；原文件集合保存在其 `basis_commit` 指定的源码提交中。

独立复核摘要保持原字节，仍记录当时完整输出的指纹；当前分发清单是该集合的子集。回归检查核对这个关系，并保护最终登记、所有本地产物与证据引用、研究代码、分析和正文。精简不代表重新执行任务或重新作出内容判断。需要重建法学变体输入时，将 `cases/legal-language-scope/` 中的原输入复制到新目录，再用对应保留变体的 `source-packet.md` 覆盖同名文件；其他输入与原例相同。

运行专项回归：

```sh
python3 -B -m unittest discover -s tests -p test_disciplinary_evaluations.py -v
```

需要Python 3.11+；完整检查仍运行 `python3 -B tools/check_core.py --test-timeout 360`。自动回归不调用模型重新审阅，独立内容判断见[复核摘要](independent-review.json)，实际覆盖见[覆盖记录](coverage.json)。
