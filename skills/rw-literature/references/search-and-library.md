# 检索记录与项目索引

仅在批量／跨库检索或项目需要反复查阅一组材料时使用。沿用现有检索记录、来源清单与阅读笔记；以下是需要能复查的信息，不是新的强制表格、文件名或登记模式。

## 批量检索的实际覆盖

按每个实际使用的数据库、网站或档案渠道留下完整检索式、执行日期、所用字段与过滤条件；排序影响取回范围时也记录。渠道语法不同，保留各自实际运行的表达式。计划中的渠道或未执行的查询明确标为计划，不混入完成记录。

分别说明界面报告的命中数、实际取回的题录数与筛选后保留数；近似值或不可取得的总量注明其性质。记录导出文件的实际位置、格式和导出范围；没有导出时如实说明。分页、接口截断、只取排序前部、账号权限、时间或语种过滤、全文不可访问等限制应随记录保留，不能把有限返回当成数据库的完整覆盖。

汇总时区别重复导入的同一题录、同一作品的不同版本，以及同一研究产生的多份报告。保留标识与关联、合并依据和采用的版本；身份未定时先保留疑问。筛除材料留下阶段和理由，全文未取得留下待核或访问限制；不要让重复记录或报告变成独立证据的额外票数。书籍、档案等没有 DOI 的材料仍可用其实际稳定标识定位。

这些记录服务于本轮问题，不规定搜够多少篇才可结束。单篇定位无需承担系统综述的流程；开展综合时按实际方法选择报告规范，不把 PRISMA 作为所有文献工作的通用门槛。

## 反复查阅的项目资料

先检查已有来源登记、书目、笔记与文件，再决定是否需要补索引。优先扩展已有材料，用主题或研究问题指向需要的章节、页码、条款、定理或段落。打印页与文件页不同则分别注明；未核对的位置标为待核，不从目录或摘要推定正文已读。

索引保留所用材料的身份、版本／版次、译本情况、稳定定位和可用的本地路径，并说明实际读到的范围。对本地原件和提取文本分辨身份，能核对时保留完整文件指纹；无法获取时注明缺口。缺页、扫描识别不稳、公式或图表未提取等情况放在对应笔记中，不能以提取成功代替阅读完整。

回答问题时读取相关原件片段，并保持三层可辨：材料本身的陈述、译述／摘要、研究者跨材料的比较与推断。跨来源结论关联实际使用的每处材料，概念相似或检索命中本身不构成支持。

来源版本、文件内容或提取结果变化后，先定位依赖它的笔记和结论，重核受影响位置再更新记录。保留旧版身份与未解决差异，不靠改写指纹把旧核对自动变成有效。已有核心登记可继续使用 Source 保存身份、Evidence 指向实际笔记或原件、Relation 说明有界主张；登记细节仍以核心协议为准，不增加字段或另建一份权威台账。

索引与材料留在研究项目中，按本次授权更新。它不表示整个集合已经读完，也不要求把整书复制成全局技能；不附带自动下载、全库重建或后台监控。
