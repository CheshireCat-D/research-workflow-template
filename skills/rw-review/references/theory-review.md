# 单次理论审查

用于给定命题、证明或理论稿的一次审查。先确认当前稿源、实际可读的文献及用户允许的动作；“只检查”时不改文件。已有 RWT 项目状态、持续登记或跨会话工作仍回到入口的项目分支。本页不是新的登记体系，也不要求初始化项目。

从关键主张到依据逐步检查，只展开当前论证涉及的义务：

- 写清对象、定义域、量词顺序、参数范围和结论。区分有限／渐近、逐点／一致、确定／概率、几乎处处／处处及不同收敛方式。检查结论是否比假设或引理实际支持的更强。
- 展开关键推断，核对依赖引理的真实条件。涉及极限、积分、求和、微分、条件期望或算子交换时，对具体对象核对可积性、支配、紧性或连续性等所需条件；不机械堆列无关定理。
- 概率论证明确概率空间、过滤、适应性／可预测性、矩和条件分布假设；区分固定参数与数据后调参、固定时刻与同时有效、确定索引与随机停时。局部化或停止后的结论延伸须有相应极限、可积性或事件包含依据。
- 对可疑命题检查边界、退化和最小情形。反例须同时满足所列假设并严格违反结论；写出参数、事件、概率或不等式。确认错误后保留仍成立部分，给出有依据的修正，不为原命题补造证明。有效替代证明或反例不因路线不同而排除。
- 对引文直接核对已提供原文的版本、页码／定理号、假设和结论，说明它支持哪一步。题录、摘要、关键词相近或检索未命中不等于原文支持或原创性证明；缺失来源明确保留待核，不编造引用。确需扩展检索时再用 `rw-literature`，不为核对一处已提供原文而加载完整检索流程。

手工证明、符号化简、有限枚举、数值实验和形式证明分别报告实际完成的范围。有限计算、脚本退出成功或未发现反例不代替无限命题的证明；只有实际运行并通过的形式化部分才称形式验证。

交付可定位的发现、推断依据、影响及必要修正；区分已确认错误、待核疑点和未覆盖部分。无需为了充实报告发明问题，也不强制每次都写修正版证明。保留原结果的条件和确定程度，正文直接陈述结果与必要条件，工具过程留在审查记录。

单次审查到报告即可。需要发展新证明／计算研究时按缺口调用 `rw-validation`；明确请求隔离多评审、返修回复或投稿准备时，回到 `rw-review` 选择对应参考，不把这些流程当作本页的默认后续。
