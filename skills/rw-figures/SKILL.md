# 科研图件

先读 [接入协议](../../core/skill-bridge.md)。单次改图无需新建研究项目。
保持用户指定或现有的绘图后端、源格式、术语和输出范围。只审阅时交付问题与建议，
不擅自重画；已有授权足以推进时，不增加固定的风格选择或方案确认关卡。

## 选择产物路线

| 请求 | 路线与边界 |
|---|---|
| 数据图 | 沿用可运行的 Python、R 或其他用户后端；先核对观察单位、变量、尺度、分组／配对和要回答的问题，再选编码。没有既定后端时说明合理选择并推进；会影响复用或交付的选择才追问。 |
| 原生可编辑示意图 | 用 SVG 的原生文本、形状、分组与连线；已有 TikZ/PGF 源或用户要求 LaTeX 源时保留 TikZ。按需读 [示意图与结构检查](references/editable-schematics.md)。 |
| 定量多面板／图像图版 | 给每个面板明确的信息职责，保留实际数据、图像、单位、尺度条及来源。裁剪、变换、合并和数据排除须有依据并记录；同一信息不靠重复换图型冒充多项证据。 |
| AI 概念插图草稿 | 仅在用户要求时使用可用的图像工具。将科学关系与视觉修辞分开；不生成实验图像、数据点或数值来替代真实结果。投稿用途核对目标刊会对该用途的当前要求，草稿状态与适用范围明确交付。 |

普通排版表格沿用表格工具。证明有效性、效应估计、样本量设计和统计检验的核心问题
交给 `rw-validation`；图形排版不能自行补足这些依据。

需要可运行的数据图演示时，可按需看 [合成双面板示例](examples/plot_demo.py)。它需要
环境中已有 Matplotlib，不自动安装依赖，演示结果不构成研究证据。

## 保留科学含义

开画前用一句话说明图形的问题，确认真正会改变含义的信息：数据／材料在哪里、
哪些关系来自原文、哪些只是作者假设、读者与最终尺寸。已可从材料推断的普通布局
选择直接说明即可，不要求每张图填写表单。

- 真实数据读取失败时停止依赖该数据的绘制，不静默切换成模拟数据。演示数据和示意
  曲线明确标为 synthetic／模拟，不能被解读成研究结果。
- 不为美观删除观测、改变轴尺度、移动数据点或增加误差线。误差条的 SD、SEM、CI、
  观察单位与 n 以实际材料为准；没有依据时保留缺口。
- 示意图的节点、箭头、方向和条件都是主张。将可直接定位的内容与推断分开；
  外观参考不授权复制其数值、标注、机构标识或特有科学内容。
- 多面板共享颜色与符号含义；对照、配对、重复测量及不同单位不因拼版而消失。
  按数据尺度选择连续／发散／分类色彩，用形状或线型辅助区分重要类别。

## 检查与交付

先确定使用场景和最终物理尺寸；目标刊会规则来自实际取得的指南，不固定一种期刊
尺寸或配色。生成后渲染并查看完整图与必要局部，在最终尺寸核对可读性、文字裁切、
遮挡、箭头端点、图例、单位与面板对应。改动后复查受影响区域。编译、结构审计和
视觉检查分别报告，均不能替代科学核验。

默认交付用户所需的可编辑源、可用导出图与刚检查过的预览，简述依据、必要的运行
方式及尚未确认的内容。原生可编辑意味着文字和图元可分别修改；把整张 PNG 放入
SVG/PPTX 不算完成此要求。SVG 可使用只读结构检查器：

```text
python3 SKILL_DIR/scripts/audit_svg_schematic.py figure.svg
```

它输出 JSON：退出 `0` 表示受支持的结构检查未发现错误，`1` 表示结构发现，`2`
表示无法审计或输入错误；并不认证科学语义、排版无碰撞或图像数据真实性。
持续项目仅登记实际生成的图件、代码和已执行检查；轻量示意图可参考
[小型 FigureSpec 示例](assets/synthetic-figure-spec.json)，无需另建平台或强制登记每个图元。
