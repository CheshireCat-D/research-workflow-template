# 可编辑示意图

在结构示意图任务中按需使用本页。数据图继续由其实际绘图代码生成；不从论文截图
估计新数据，不让图像模型重绘定量标记。

从材料先列出所需节点和有向关系，保留原文术语、条件与不确定性。复杂图或反复修订
时，可使用 [FigureSpec 示例](../assets/synthetic-figure-spec.json) 的小型对象：
来源片段、节点／边 id、直接信息或推断、布局决定、输出文件。它是可选工作说明，
不是项目登记模式或自动验证语义的形式语言。来源不足会改变科学结构时才询问；
普通布局判断可直接提出并实施。

## SVG 与 TikZ

- SVG 以有物理单位的 `width`、`height` 和对应 `viewBox` 确定画布。为需要独立修订
  的节点／边命名稳定 id；一个节点用一个组包含其形状和原生 `<text>`。改变拓扑时
  同步修改说明，单纯改色不应改变箭头方向、标签或数据。
- 用 `<title>`、`<desc>` 和本地 `aria-labelledby` 指向说明。连线表达真实的顺序、
  数据流、作用或假设关系；仅装饰性的线可去掉。推断边需在图注或图中明确区分。
- 保留已有 TikZ 的命名坐标和语义样式；编译、渲染后检查文字、交点、箭头端点和
  数学关系。只有确实完成转换时，才把输出称为可编辑 SVG 或其他格式。
- 原文结构与设计解释分开。布局、颜色、相对位置通常是设计选择，不能自动写成
  真实流程、因果或定量距离。

[SVG 示例](../assets/synthetic-workflow.svg) 明示为 synthetic：两个实线关系直接来自
例子的虚构说明，虚线反馈只是为展示推断标记而提出的可能关系。示例不提供研究证据。

## 只读结构检查

从当前技能目录运行：

```text
python3 scripts/audit_svg_schematic.py path/to/figure.svg
```

脚本仅用 Python 标准库读取 UTF-8 SVG，向标准输出写 JSON，不联网、不渲染、不执行
SVG，也不修复或写回文件。没有外部资源加载能力。它检查：

- XML 可解析且根元素为 SVG；拒绝 DTD、实体声明和外部样式处理指令。
- `width`、`height` 为有限正数，使用 `px/pt/pc/mm/cm/in`；`viewBox` 有四个有限
  数值且宽高为正。相对单位和百分比在该检查器中不受支持。
- 重复／空 id；本地 `href`、`url(#id)` 和 ARIA id 引用是否可解析。
- 脚本、事件处理器、动态修改、`foreignObject`、外链、XML base、CSS import 和非本地
  资源引用。为保持检查范围可解释，CSS 转义在该检查器中不受支持。
- 至少存在一个非空原生 `<text>`；缺少图件说明和包含位图时给出有限提示。

退出 `0` 仍可能有 warning，必须读 findings。退出 `1` 的错误应修复后重新检查；
退出 `2` 不能报告结构检查通过。脚本对检查集合以外的 SVG 语法不做完整有效性认证。
原生文本计数不证明全部可见标签均可编辑；嵌入位图的内容不被验证。

检查器不推测文本或曲线的完整几何边界，不检测碰撞、箭头是否指对节点、色觉适配、
最终字号或科学语义。继续用实际渲染器导出预览，逐项查看所修改区域和完整图。
