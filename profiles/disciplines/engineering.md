# 工学语境

画像 ID：`engineering`；版本：`0.1`。先明确真实使用需求、技术对象、系统边界、资源与验证环境，不以原型能运行替代用户目标。

- 系统、设备和软件原型读 [工程设计](../methods/engineering-design.md)，建立需求与验证依据对应，保留失败与未满足项。
- 建模、仿真、性能比较读 [计算研究](../methods/computational.md)，实物测量读 [测量与实验](../methods/measurement-experiment.md)。硬件、仿真、单位测试与真实使用结果分开报告。
- 涉及用户研究时按设计加入 [量化实证](../methods/empirical-quantitative.md) 或 [定性研究](../methods/qualitative.md)，不把少量满意反馈当作安全性或总体有效性。

理论可行、仿真可行、原型达标和真实部署是不同交付层级。接口、版本、环境和不可公开的商业材料要可追溯；实际部署、设备控制、人员试用和安全相关操作按 [治理](../governance.md) 与授权范围处理。登记见 [接入协议](../../core/skill-bridge.md)。
