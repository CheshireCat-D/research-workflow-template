# 历史与阐释：史料解释纵向切片

画像 ID：`historical-interpretive`；版本：`0.1`；当前重点：可定位档案／文本材料与竞争解释。艺术阐释、口述史、历史比较等其他变体尚未完整验证。登记方式见 [接入协议](../../core/skill-bridge.md)。

## 材料身份与语境

逐件确认实际获得的材料版本、日期、生成者、文类、目的与保存来源。区分原件、抄件、转述和后来的解释；资料缺失的信息保留未知，不以常识填入作者或动机。虚构测试材料明确标记为虚构，不能当真实档案证据。

引用给出材料 ID 与页、节、行或节录定位。正文节录、编者说明和目录元数据承担不同证据作用；翻译和删节注明范围。材料访问与再分发权利按实际情况处理，材料不公开不等于研究不能进行，但不能据此复制或外发原件。

## 检验解释关系

从研究问题写出待解释现象与时间范围，分别列出材料直接记载的内容和研究者的推论。检查时间先后、叙述位置、参与者利益及可见范围。自述能证明有人作过某种表述，不自动证明其陈述就是事件的唯一原因。

遇到竞争解释，逐条说明各自获得的支持、限制、挑战及可能并存的关系。多个材料可能共同依赖同一来源，不能按条目数当作独立佐证。材料沉默只有在该材料通常应记载有关事项且保存范围足够时才可能构成有意义的反向依据。

合理保留不同解释及证据不对称；不为得出明确结论而强行平均，也不以存在分歧宣布任何解释都同样成立。新的材料可能改变解释排序，说明什么材料最有辨别力。

## 交付与登记

交付可定位的材料对照、明确标注推论的解释文本，以及尚缺语境或竞争解释。文风可以简洁有力，但不把“与……相容”“提示……”改写成“证明唯一原因”。

持续项目把来源、材料和解释性 statement 分开登记，以 supports、qualifies、challenges 或 contextualizes 表示有范围的关系。保留相互竞争的解释，不用登记通过或支持关系数量替代史学判断；本切片也不构成专业史学同行审查。
